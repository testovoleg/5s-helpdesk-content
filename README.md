# 5s-helpdesk

База знаний техподдержки 5SYSTEMS: статьи формата «проблема и решение».

Контекст продукта: [5systems.ru/articles](https://www.5systems.ru/articles)

## Структура

Материалы разложены по трем корневым разделам:

```
articles/                    # статьи базы знаний, по продуктам
├── 5S AUTO/
│   ├── Администрирование/
│   │   ├── Исправление ошибок версий/
│   │   └── Лицензирование 5S AUTO/
│   ├── Внешние обработки/
│   ├── Интеграции/
│   ├── Маркировка/
│   ├── Отчеты/
│   └── Торговое оборудование/
├── 5S LINK/
├── 5S Chat/
├── 5S TSD/
├── 5S Remzona/
├── 5S AI Agent/
├── 5S Pay/
└── 5S Cloud/

tips/                        # советы формата «проблема и решение»
├── 5S AUTO/
├── Оборудование/
│   ├── Банковские терминалы/
│   └── Кассы ККМ/
└── Техподдержка/

lessons/                     # уроки
```

Каждая статья — отдельная папка с уникальным именем:

```
.../тема-статьи/
├── tema-stati.md
└── attachments/             # скриншоты и файлы статьи
```

## Индекс материалов

`index.json` в корне — список статей и даты последнего обновления (для автоматического анализа изменений).

Пересобрать вручную:

```bash
python3 .scripts/generate-index.py
```

Чтобы индекс обновлялся при коммите, один раз включите hooks репозитория:

```bash
git config core.hooksPath .githooks
```

# Архив базы знаний 5SYSTEMS

Ветка `archive` хранит материалы, снятые с публикации: устаревшие статьи, статьи с пометкой «требует актуализации», статьи про WhatsApp. В рабочей ветке `Katya` и в публикуемой `master` этих материалов нет, ссылки на них оттуда убраны. Решение Кати, 15.09.2026.

Материалы лежат по тем же путям, где они были в `Katya` (кроме «Категорий обращения» — она сразу перенесена в архив и положена в раздел «Задачи»). Ссылки из архивных статей на другие материалы могут не работать: цели остались в `Katya`.

## Как работать с архивом

- **Добавить статью в архив:** на ветке `archive` выполнить `git checkout Katya -- "<путь к папке статьи>"`, закоммитить, затем удалить папку из `Katya`, убрать ссылки на неё и строки в `.order`, слить `Katya` в `master`. Список слагов архивных статей в конвейере переноса — `ARCHIVED` в `~/.claude/scripts/5s-transfer/rewire.py`: ссылки на них при пересборке снимаются (в тестах остаются ссылками на старую базу знаний).
- **Вернуть статью из архива:** `git checkout archive -- "<путь>"` на ветке `Katya`, вернуть строку в `.order` раздела, убрать слаг из `ARCHIVED`, восстановить ссылки.
- Ветку `archive` в `master` и `Katya` не сливать.

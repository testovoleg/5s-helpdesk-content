## Введение

Справочник **"Организации"** содержит список организаций, по которым может производиться учет по компании.

Организациями могут быть:

- юридическое лицо;
- частный предприниматель;
- частное лицо.

В справочнике хранится вся информация, которая идентифицирует организации, а также содержатся дополнительные сведения, необходимые для ведения учета.

## Добавление организации

### Переход к справочнику "Организации"

Справочник "Организации" находится в разделе меню *Администрирование → Компания → Структура компании → Организации:*

![Организации - Расположение](attachments/01-organizacii-raspolozhenie.png)

### Основные данные

Следует задать *наименование* и *полное наименование* организации. Для каждой организации может быть назначен *префикс* номера документов, который будет использоваться при создании документов в программе.

На вкладке **"Основные данные"** необходимо заполнить данные: форма собственности, ИНН, ОГРН, систему налогообложения[\*](#snoska):

![Организации - Системы налогообложения](attachments/02-organizacii-sistemy-nalogooblozheniya.png)

<a id="snoska"></a>*\*Подробнее см. урок "[Как настроить систему налогообложения](../../../../lessons/Урок%202.%20Структура%20компании/Как%20настроить%20систему%20налогообложения/kak-nastroit-sistemu-nalogooblozheniya.md)".*

Параметры *Руководитель*, *Главный бухгалтер*, *Кассир* и *МОЛ* в поле “Ответственные лица” не обязательны для заполнения.

### Контактная информация

На вкладке **"Контактная информация"** необходимо заполнить рабочий и контактный телефон, юридический и фактический адрес, ссылку на карту, сайт организации и электронную почту:

![Организации - Параметры](attachments/03-organizacii-parametry.png)

### Банковские реквизиты

На вкладке **"Счета и подтверждающие документы"** необходимо добавить *банковские реквизиты.*

Справочник "Банковские счета" содержит счета всех юридических и физических лиц: собственных и сторонних.

Для каждого контрагента или собственной организации можно выбрать *основной* банковский счет, который будет подтягиваться по умолчанию в платежные документы.

При добавлении расчетного счета обязательными для заполнения параметрами являются *Номер счета, Банк, Валюта счета, Вид счета:*

![Организации - Добавление расчетного счета](attachments/04-organizacii-dobavlenie-raschetnogo-scheta.png)

Банк следует выбрать из справочника “Банки” (расположение в меню программы: *Финансы → вкладка “Касса и банк” → раздел "Прочее"):*

![Организации - Банки](attachments/05-organizacii-banki.png)

### Логотип организации

Для организации есть возможность добавить *логотип,* который будет отображаться в печатных формах. Для этого следует нажать на кнопку “Логотип организации” и загрузить файл изображения:

![Организации - Логотип](attachments/06-organizacii-logotip.png)

## Основные реквизиты по организации и подразделению

Для каждой пары «организация + подразделение» можно задать реквизиты, которые будут подставляться по умолчанию в новые документы: основной склад, склад расходных материалов, касса и подразделение для пробития чеков по услугам. Например, инвентаризация или возврат товаров поставщику по определенной организации будут создаваться сразу с нужным складом.

Чтобы задать реквизиты:

1. В справочнике "Организации" выделите строку с нужной организацией и выберите **«Перейти» → «Основные реквизиты по организации и подразделению»**:

   ![Организации - Переход к основным реквизитам](attachments/09-organizacii-perehod-k-osnovnym-rekvizitam.png)

2. Откройте запись с нужным подразделением или создайте новую.
3. Заполните реквизиты и нажмите **«ОК»** или **«Записать»**:

   ![Организации - Запись основных реквизитов](attachments/10-organizacii-osnovnye-rekvizity.png)

Реквизиты записи:

- *Основной склад* – склад, который подставляется в документы по этой организации и подразделению;
- *Основной склад расходных материалов* – склад, с которого списываются расходные материалы;
- *Основная касса* – касса для документов по этой организации и подразделению;
- *Подразделение для пробития чеков по услугам* – подразделение, от имени которого пробиваются чеки на услуги.

Реквизиты задаются для каждой пары «организация – подразделение» отдельно: если у организации несколько подразделений, заполните запись для каждого из них.

## Предопределенный элемент справочника "Организации"

В справочнике “Организации” обязательно должен быть *предопределенный элемент “-”*, который не следует трогать и изменять. Предопределенный элемент “-” необходим для простого и беспроблемного добавления новых подразделений с разными организациями и их типами налогообложения:

![Предопределенная организация](attachments/07-predopredelennaya-organizaciya.png)

Организация "-" добавляется к сгруппированным по определенным факторам подразделениям:

![Организации - Предопределенный элемент - Группировка](attachments/08-organizacii-predopredelennyy-element-gruppirovka.png)

## Введение

Лиды, сделки и процессы в системе можно просматривать в двух режимах: список и канбан. Описание работы с канбаном см. в статье «[Канбан сделок](../Канбан%20сделок/kanban-sdelok.md)».

Список сделок представляет собой таблицу, в которую выведена вся основная информация по текущим сделкам:

![Список сделок](attachments/01-spisok.png)

Для переключения между режимами используется кнопка на верхней панели **«Список / Канбан»**:

![Переключение между списком и канбаном](attachments/02-pereklyuchenie.png)

## Интерфейс списка сделок

Информация по лидам и сделкам, входящим в список, по умолчанию выводится в разбивке на следующие колонки:

- Номер
- Дата
- Клиент
- Телефон
- Этап
- Сумма
- Автомобиль
- Госномер
- Задачи
- Ответственный
- Подразделение
- Активность
- Рекламный канал
- Комментарий

При необходимости можно добавить другие колонки или убрать ненужные: кликните правой кнопкой мыши в любом месте таблицы и перейдите в **«Настройку списка»**:

![Настройка списка колонок](attachments/03-nastroyka-spiska.png)

Настройка списка сохраняется для текущего рабочего стола и применяется при следующем открытии.

По умолчанию открывается канбан со сделками, созданными за последние 3 месяца, либо с теми, у которых за это время менялся этап или ответственный. При необходимости можно установить для себя различные отборы и фильтры сделок — см. ниже.

## Отборы и фильтры

[![Видео: отборы в режиме списка](attachments/20-video-otbory-v-spiske.png)](https://edu.5systems.ru/video/Rabochij_stol/Otbory_v_rezhime_spiska.mp4)

### Быстрые фильтры

Быстрые фильтры позволяют, например, отобразить только свои сделки либо задать период по дате создания сделок или последней активности по ним. Нажмите кнопку с лупой на панели отбора, задайте нужные критерии и нажмите **«Найти»**:

![Быстрые фильтры сделок](attachments/04-bystrye-filtry.png)

Установленные фильтры сохраняются для текущего рабочего стола и будут действовать по умолчанию при следующем открытии списка сделок.

### Отборы по значению в колонках

Для удобства работы со списком есть возможность устанавливать отборы по значениям в каждой колонке.

#### 1. Отбор по обращениям

При клике правой кнопкой мыши по колонкам **«Номер»**, **«Дата»** или **«Клиент»** открывается меню, в котором можно установить отбор по первичным либо повторным клиентам, а также задать временной интервал:

![Меню отбора по обращениям](attachments/05-otbor-po-obrashcheniyam.png)

Например, можно оставить в списке только первичных клиентов:

![Результат отбора по первичным клиентам](attachments/06-otbor-pervichnye-rezultat.png)

#### 2. Отбор по сообщениям

При клике правой кнопкой мыши на столбце **«Телефон»** можно установить отбор по непрочитанным сообщениям либо по клиентам, основным каналом общения с которыми являются мессенджеры:

![Меню отбора по сообщениям](attachments/07-otbor-po-soobshcheniyam.png)

#### 3. Отбор по этапу

Есть возможность выбрать только сделки, находящиеся на определенном этапе, например «Неразобранное»:

![Меню отбора по этапу](attachments/08-otbor-po-etapu.png)

Также можно сортировать сделки по этапам — по возрастанию или по убыванию:

![Сортировка сделок по этапам](attachments/09-sortirovka-po-etapam.png)

#### 4. Отбор по сумме

При установке отбора по сумме открывается меню со следующими значениями:

- Не указана
- < 1000 руб.
- \> 1000 руб.
- \> 10 000 руб.
- \> 50 000 руб.

Например, можно оставить в списке только сделки, сумма по которым больше 1000 рублей:

![Отбор сделок по сумме](attachments/10-otbor-po-summe.png)

#### 5. Отбор по автомобилям

При установке отбора по автомобилю открывается список марок всех автомобилей из текущего списка сделок — можно вывести только автомобили определенной марки:

![Отбор сделок по автомобилям](attachments/11-otbor-po-avtomobilyam.png)

#### 6. Отбор по задачам

Есть возможность установить отбор сделок по просроченным задачам либо по сделкам без задач:

![Отбор сделок по задачам](attachments/12-otbor-po-zadacham.png)

#### 7. Отбор по ответственному

Есть возможность установить отбор сделок по ответственному — в меню предлагается выбор среди пользователей, которые назначены ответственными для сделок в текущем списке:

![Отбор сделок по ответственному](attachments/13-otbor-po-otvetstvennomu.png)

#### 8. Отбор по подразделению

Есть возможность установить отбор сделок по подразделению:

![Отбор сделок по подразделению](attachments/14-otbor-po-podrazdeleniyu.png)

#### 9. Отбор по активности

Активность — это последние дата и время следующих действий по сделке: создание документов, созвон или переписка с клиентом, прикрепление комментария в сделке.

При установке отбора по последней активности открывается меню со следующими вариантами:

- Час
- 2 часа
- Сегодня
- Вчера
- Неделя
- Месяц
- Установить интервал

![Отбор сделок по последней активности](attachments/15-otbor-po-aktivnosti.png)

#### 10. Отбор по рекламным каналам

Есть возможность установить отбор по рекламным каналам: выделите ячейку с нужным рекламным каналом, кликните правой кнопкой мыши и выберите **«Отбор по значению в текущей колонке»**:

![Отбор сделок по рекламному каналу](attachments/16-otbor-po-reklamnym-kanalam.png)

### Отбор по значению в ячейке

Также можно установить отбор по значению в любой ячейке списка — например, выбрать все сделки по определенному клиенту:

![Отбор по значению в ячейке](attachments/17-otbor-po-yacheyke.png)

### Комплексная настройка отборов

Для единовременной установки всех необходимых отборов перейдите в окно **«Отбор сделок → Строки»** и задайте все нужные настройки сразу:

![Комплексная настройка отборов](attachments/18-kompleksnaya-nastroyka.png)

### Сохранение отборов

Установленные для просмотра списка сделок отборы можно сохранить и затем просто выбирать из списка нужную настройку — см. описание в статье «[Сохранение настроек просмотра сделок](https://www.5systems.ru/help/sokhranenie-nastroek-prosmotra-sdelok)».

### Снятие отборов

Для снятия установленных отборов нажмите кнопку **«Отбор строк»** и кликните на тот отбор, который необходимо снять, либо нажмите **«Отключить отбор»** — снимутся все заданные отборы:

![Снятие отборов](attachments/19-snyatie-otborov.png)

# Новый релиз 2.8.2

<table><tr><td><b>Время чтения:</b> 4 мин.</td><td><b>Обновлено:</b> 15.05.2025</td></tr></table>

🆕 Мы выпустили **новый релиз 2.8.2**! Встречайте обновления:

✅ Реализовали новую **интеграцию с WhatsApp Business API (WABA) v.3**, которая позволяет полноценно использовать все функции канала WhatsApp для общения с клиентами:<br>
➱ автоматизация взаимодействия с клиентами с помощью бота;<br>
➱ массовые рассылки;<br>
➱ кнопки и опции в сообщениях;<br>
➱ расширенные возможности оформления профиля компании;<br>
➱ стартовое меню для новых пользователей;<br>
➱ меню быстрых действий для перехода в ЛК приложения 5S Link, записи на ремонт, просмотра бонусного счета и т.д.<br>
Подробнее см. статьи на 📚 Базе знаний в разделе WhatsApp

📲 Расширили возможности приложения ***5S Link***:

1. Самостоятельная *оплата* клиентом *бонусами;*
2. *Сохранение ярлыка* приложения на рабочий стол.

Подробнее см. в статье на 📚 Базе знаний: [Настройка приложения 5S LINK v2](../../Приложение%205S%20LINK/Настройка%20приложения%205S%20LINK%20v2/nastroyka-prilozheniya-5s-link-v2.md#самостоятельная-оплата-клиентом-бонусами)

💸 Добавили новые возможности работы с ***СБП***:

1. Формирование *платежной ссылки* из [Заказа покупателя](../../Работа%20с%20заказами/Работа%20с%20заказами%20покупателя/rabota-s-zakazami-pokupatelya.md);
2. *Автоматический возврат* клиенту через *СБП* при пробитии чека на возврат.

Подробнее см. в статье на 📚 Базе знаний: [Работа с СБП](../../Банки%20и%20платежные%20системы/Система%20быстрых%20платежей/Работа%20с%20СБП/rabota-s-sbp.md#возврат-оплаты-по-сбп).

🅰️ Реализовали интеграцию с ***СБП Альфа-банка***.<br>
Подробнее см. новую статью на 📚 Базе знаний: [Подключение СБП Альфа-Банка](../../Банки%20и%20платежные%20системы/Система%20быстрых%20платежей/Подключение%20СБП%20Альфа-Банка/podklyuchenie-sbp-alfa-banka.md)

⏬ Добавили ***а******втоматическую загрузку банковских выписок*** из банков Сбербанк, Т-Банк и Альфа-Банк. Теперь не нужно загружать выписки вручную, они загружаются в фоновом режиме.<br>
Подробнее см. статьи в новом разделе на 📚 Базе знаний: [Банковские выписки](../../Банки%20и%20платежные%20системы/Банковские%20выписки/).

📱 *Разработали новое* ***приложение 5S Pay*** с двумя режимами работы: *“Терминал СБП”* и *“Электронный кассир”.*<br>
Подробнее см. новую статью на 📚 Базе знаний: [Настройка приложения 5S Pay](../../Касса/Настройка%20приложения%205S%20Pay/nastroyka-prilozheniya-5s-pay.md).

👨🏻💻 Добавили возможность *создания и редактирования* ***пользователей 5S Cloud***.<br>
➱ *5S Cloud* – это экосистема облачных продуктов и сервисов компании 5SYSTEMS, в которую входят: Контакт-центр 5S Chat, Терминал 5s Pay, Шлюз Export API, Шлюз Part API и другие. Все составляющие экосистемы связаны воедино с помощью общей системы аутентификации.<br>
➱ *Учетные записи* нужны для авторизации в приложениях 5S Cloud.<br>
Подробнее см. новую статью на 📚 Базе знаний: [Создание и редактирование пользователей 5S Cloud](../../Администрирование%20и%20настройка%20системы/Создание%20и%20редактирование%20пользователей%205S%20Cloud/sozdanie-i-redaktirovanie-polzovateley-5s-cloud.md).

🔓 Доработали ***RLS и роли***:

1. *Расширили механизм RLS* на документы “Начисление заработной платы”, регистр накопления “Начисления сотрудникам” и документы “Отражение затрат на маркетинг”.

   Подробнее см. в статье на 📚 Базе знаний: [Доступ к данным по подразделениям (RLS)](../../Администрирование%20и%20настройка%20системы/Доступ%20к%20данным%20по%20подразделениям%20%28RLS%29/dostup-k-dannym-po-podrazdeleniyam-rls.md).

2. В АРМ “Клиенты и автомобили” в таблицу “История обслуживания” вывели *заказ-наряды других филиалов* для пользователей RLS.

   Ранее пользователю RLS были недоступны для просмотра документы по чужим подразделениям, теперь *все* документы выводятся в таблицу, но заказ-наряды по *недоступным подразделениям* открываются *в упрощенной форме.*<br>
   Подробнее см. в статье на 📚 Базе знаний: [Доступ к данным по подразделениям (RLS)](../../Администрирование%20и%20настройка%20системы/Доступ%20к%20данным%20по%20подразделениям%20%28RLS%29/dostup-k-dannym-po-podrazdeleniyam-rls.md#арм-клиенты-и-автомобили).

3. Добавили новые *роли пользователей* для настройки *доступа* к работе с отчетами:<br>
  ➱ Отчеты по финансам;<br>
  ➱ Отчеты по маркетингу;<br>
  ➱ Отчеты по продажам;<br>
  ➱ Отчеты по кассе.

Подробнее см. в статье на 📚 Базе знаний: [Роли пользователей](../../Пользователи%20и%20права/Роли%20пользователей/roli-polzovateley.md#описание-ролей).

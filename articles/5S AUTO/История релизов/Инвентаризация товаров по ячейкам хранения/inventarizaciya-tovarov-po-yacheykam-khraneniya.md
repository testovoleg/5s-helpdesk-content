# Инвентаризация товаров по ячейкам хранения

<table><tr><td><b>Время чтения:</b> 1 мин.</td><td><b>Обновлено:</b> 22.04.2022</td></tr></table>

<sub>Источник: https://www.5systems.ru/news/inventarizaciya-tovarov-po-yacheykam-khraneniya</sub>

Создан механизм **Инвентаризации товаров по ячейкам хранения**:

- создание ячеек хранения с разбивкой по группам;
- заполнение документа "Инвентаризация" всеми ячейками склада или по группам ячеек;
- автозаполнение состава товаров в документе по ячейкам хранения.

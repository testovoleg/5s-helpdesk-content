# Доработан Акт сверки взаиморасчетов

<table><tr><td><b>Время чтения:</b> 1 мин.</td><td><b>Обновлено:</b> 31.05.2022</td></tr></table>

<sub>Источник: https://www.5systems.ru/news/dorabotan-akt-sverki-vzaimoraschetov</sub>

Выполнен ряд доработок для документа **Акт сверки взаиморасчетов**:

***Что было сделано:***

1. Убрана видимость реквизита "Сделка" в табличных частях документа.
2. При заполнении документа (Заполнение → Заполнить по взаиморасчетам) убрано разбиение данных по сделкам.
3. Из печатной формы удалена колонка "Сделка".
4. Добавлен диалог при заполнении документа: "Включить все документы / только регламентированного учета / только нерегламентированного учета (особенности работы со сводными актами).
5. Добавлен вопрос "Загружаем" с вариантами ответов "Все документы" и "Регламентированный учет".

Для подробной информации смотрите статью на Базе знаний: [Акт сверки взаиморасчетов](../../Учет%20взаиморасчетов/Акт%20сверки%20взаиморасчетов/akt-sverki-vzaimoraschetov.md).

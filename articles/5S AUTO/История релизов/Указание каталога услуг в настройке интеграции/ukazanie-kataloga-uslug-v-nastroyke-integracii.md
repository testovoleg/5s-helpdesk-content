# Указание каталога услуг в настройке интеграции

<table><tr><td><b>Время чтения:</b> 1 мин.</td><td><b>Обновлено:</b> 08.04.2022</td></tr></table>

<sub>Источник: https://www.5systems.ru/news/ukazanie-kataloga-uslug-v-nastroyke-integracii</sub>

Реализована возможность указания каталога услуг при настройке интеграции с внешними сервисами. Теперь вы можете иметь несколько мобильных приложений с разным списком услуг.

***Что было сделано:***

- Механизм отображения работ доработан для Мобильного приложения и для сайта.
- В справочник Интеграции для мобильного приложения добавлен параметр "Каталоги услуг для внешних сервисов": он позволяет выбрать группы работ для каждой интеграции.

![](attachments/01-skrin.png) Реализовали интеграцию с ***системой маркировки Честный знак*** для ведения учета маркированных товаров.

Для *масел и автожидкостей* обязательная маркировка и регистрация в системе началась с 2025 г., передача сведений о выводе из оборота при продаже станет обязательной с 1 апреля 2026 г. Также запущен эксперимент для маркировки *автозапчастей* с 25 февраля 2025 г. по 28 февраля 2026 г.

*В 5S AUTO теперь можно:*

<div style="margin-left: 22px">

➱ настроить номенклатуру для учета разных типов маркированных товаров;<br>
➱ сканировать коды маркировки при поступлении и продаже и проверять их в “Честном знаке” в автоматическом режиме;<br>
➱ управлять всеми этапами оборота маркированных товаров;<br>
➱ видеть в документах статусы кодов маркировки и понимать, что с ними нужно делать;<br>
➱ фильтровать документы по статусам;<br>
➱ получать полную информацию о маркированных товарах через API Честного знака;<br>
➱ обновлять токены для работы с API Честного знака из программы;<br>
➱ отражать частичное выбытие маркированного товара с передачей сведений в ГИС МТ;<br>
➱ исключить нарушения при работе с маркировками.

</div>

> 📚 *См. новый раздел инструкций [Маркировка](../../Маркировка/) на Базе знаний – от подключения к «Честному знаку» до вывода из оборота маркированных товаров*

![TSD](attachments/02-tsd.png) Разработали ***5S TSD*** – вспомогательное приложение для пользователей 5S AUTO для упрощения учета товаров, в частности товаров с маркировкой “Честного Знака”. Приложение 5S TSD устанавливается сотрудникам склада на смартфон, к которому также подключается сканер штрихкодов через Bluetooth. Интерфейс приложения синхронизирован с 5S AUTO – происходит мгновенный обмен данными.

> 📚 *Подробнее см. статью на Базе знаний: [Работа с приложением 5S TSD](../../Склад%20и%20запчасти/Работа%20с%20приложением%205S%20TSD/rabota-s-prilozheniem-5s-tsd.md)*

![](attachments/03-skrin.png) Разработали приложение ***5S Chat**\** – *контакт-центр* для пользователей 5S AUTO:

<div style="margin-left: 22px">

➱ *мультиканальный мессенджер* для взаимодействия со всеми текущими чатами с клиентами и внутри компании;<br>
➱ удобный *обмен файлами* – все вложения из переписки через 5S Chat (фото, видео, сканов документов и т.д.) сохраняются в облачном хранилище 5SYSTEMS. Файлы можно прикрепить к документу в программе, а также отправить клиенту.

</div>

*＊Сервис 5S Chat доступен клиентам 5SYSTEMS после его подключения через отдел продаж (оплачивается по отдельному [тарифу](https://www.5systems.ru/services/kontakt-centr-5s-chat)).*

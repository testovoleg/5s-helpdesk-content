# Добавлена хоз. операция «Сводный акт»

<table><tr><td><b>Время чтения:</b> 2 мин.</td><td><b>Обновлено:</b> 01.03.2022</td></tr></table>

<sub>Источник: https://www.5systems.ru/news/dobavlena-khoz-operaciya-svodnyy-akt</sub>

Добавлена хоз. операция "**Сводный акт**" для документа "Реализация товаров" для упрощения работы с корпоратиными клиентами. Теперь клиенту по итогу периода можно создать один сводный акт и включить в него все заказ-наряды и реализации.

Как это работает:

1. Добавлены реквизиты начала и окончания периода документа *_5с_НачалоПериода, _5с_КонецПериода*. На форме документа добавлена возможность редактирования периода для данной хозяйственной операции.
2. Добавлен реквизит табличной части "Товары" *ДокументОснование*, который заполняется заказ-нарядом.
3. Добавлена возможность заполнения табличной части заказ-нарядами за выбранный период по Контрагенту и подразделению в состоянии "Закрыт".
4. В конфигурацию добавлены обработки для печатных форм: "Сводный акт" и печати заказ-нарядов по акту (любая форма заказ-наряда по выбору).
5. При проведении закрывается дебиторская задолженность по заказ-нарядам, заказ-нарядам устанавливается признак "не РУ" (при записи). Формируется дебиторская задолженность по Сводному акту. Для корректной работы рекомендуется вести учет задолженности по отдельным договорам для заказ-нарядам и сводным актам. Всю оплату от контрагента проводить по договору Сводного акта.
6. При проведении двигаются границы по всем договорам заказ-нарядов и договору Сводного акта.

Для подробной информации смотрите статью на Базе знаний: [Сводный акт](../../Автосервис/Сводный%20акт/svodnyy-akt.md).

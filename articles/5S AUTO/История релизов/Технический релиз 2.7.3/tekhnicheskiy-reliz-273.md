# Технический релиз 2.7.3

<table><tr><td><b>Время чтения:</b> 1 мин.</td><td><b>Обновлено:</b> 08.07.2024</td></tr></table>

<sub>Источник: https://www.5systems.ru/news/tekhnicheskiy-reliz-273</sub>

📢 Мы выпустили **технический релиз 2.7.3**, в который вошли следующие изменения в программе:

---

🚗 Обновлен ***API TecDoc***[\*](#snoska) для *расшифровки VIN-номеров автомобилей.*<br>
<a id="snoska"></a>\*Для работы с сервисом предварительно должна быть настроена интеграция с [API 5S AUTO](../../Администрирование%20и%20настройка%20системы/API%205S%20AUTO/api-5s-auto.md).

---

📲 Обновлена интеграция с ***WhatsApp Business API*** через *Cloud API* – новую облачную версию WABA. См. официальную информацию на сайте [360dialog](https://www.360dialog.com/partner-updates/ultimate-guide-to-use-cloud-api).

С 15 мая стало невозможно подключать новые номера телефонов с помощью старого On-Premise API, с января 2024 года обновления запускаются только в Cloud API, с октября 2025 года работа старого API будет прекращена навсегда.

Теперь можно регистрировать новые учетные записи через новый Cloud API.

# Упрощение настройки системы налогообложения

<table><tr><td><b>Время чтения:</b> 1 мин.</td><td><b>Обновлено:</b> 19.04.2022</td></tr></table>

<sub>Источник: https://www.5systems.ru/news/uproschenie-nastroyki-sistemy-nalogooblozheniya</sub>

Выполнено упрощение настройки системы налогообложения:

1. В справочник "Организации" добавлена галочка "Используется патентная система налогообложения". При выборе выводится гиперссылка "Патенты".
2. В справочник "Подразделения" добавлен переключатель "Налогообложение по организации / Патентная система налогообложения". В случае патента выводится реквизит "Патент" – выбор из списка патентов по организации.

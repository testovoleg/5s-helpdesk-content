# Добавлен функционал для отражения оплат через СБП

<table><tr><td><b>Время чтения:</b> 1 мин.</td><td><b>Обновлено:</b> 19.07.2022</td></tr></table>

<sub>Источник: https://www.5systems.ru/news/dobavlen-funkcional-dlya-otrazheniya-oplat-cherez-sbp</sub>

Расширен функционал программы для возможности отражения в программе приема **оплаты через СБП (Системы быстрых платежей)**. Функционал доступен начиная с релиза 2.2.5.

***Что было изменено:***

1. Произведена корректировка алгоритма проведения чека на оплату (корректировка на эквайера).
2. Сделаны доработки для упрощения настройки функционала.

Для подробной информации смотрите статью на Базе знаний: ***[Отражение оплаты через СБП](../../Касса/Отражение%20оплаты%20через%20СБП/otrazhenie-oplaty-cherez-sbp.md)***.

# Новый механизм создания пользователей

<table><tr><td><b>Время чтения:</b> 1 мин.</td><td><b>Обновлено:</b> 16.03.2022</td></tr></table>

<sub>Источник: https://www.5systems.ru/news/novyy-mekhanizm-sozdaniya-polzovateley</sub>

Было реализовано упрощение процедуры **создания пользователей и сотрудников**:

1. Добавлена кнопка "Быстрый ввод", нажатием на которую открывается новая форма с основными реквизитами.
2. Создана форма добавления шаблона создания пользователей. Один раз задайте параметры для сотрудников по каждой должности и сэкономьте время при вводе новых пользователей в дальнейшем.

Для подробной информации смотрите статью на Базе знаний: [Мастер быстрого ввода пользователей и сотрудников](../../Пользователи%20и%20права/Мастер%20быстрого%20ввода%20пользователей%20и%20сотрудников/master-bystrogo-vvoda-polzovateley-i-sotrudnikov.md).

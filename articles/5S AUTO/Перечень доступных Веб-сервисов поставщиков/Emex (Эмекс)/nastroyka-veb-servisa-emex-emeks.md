## Описание

Обработчик предназначен для работы с Веб-сервисами компании **"Emex"**.

**Для использования Веб-сервисов Emex (Эмекс) необходимо:**

1. Быть зарегистрированным на сайте поставщика (emex.ru).
2. Прислать заявку на подключение через ресурс [http://www.emex.ru/ws](http://www.emex.ru/ws) (если вы работаете через оптовика (представителя), направьте ему заявку на подключение) с указанием IP-адресов, с которых будет осуществляться подключение к Веб-сервисам.

**Места использования Веб-сервисов:**

- Проценка;
- Отправка Веб-заказа поставщику ИЛИ размещение заказа в корзине поставщика.

После получения всех необходимых для подключения параметров выполняются следующие действия для Веб прайс-листа:

1. Заполнение параметров подключения (см. *Параметры подключения*).
2. Сохранение параметров подключения.
3. Проверка соединения путем нажатия кнопки-ссылки "Проверить соединение".
4. Настройка опций методов (см. *Опции методов*).
5. Настройка параметров проценки (см. [*Создание и настройка Веб прайс-листа→Настройка параметров для проценки*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-проценки)).
6. Настройка параметров отправки заказа (см. [*Создание и настройка Веб прайс-листа→Настройка параметров для отправки заказа поставщику*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-отправки-заказа-поставщику)).
7. Сохранение всех изменений.

## Параметры подключения

Параметры подключения к Веб-сервису поставщика настраиваются на вкладке "Параметры сервиса".

Для подключения Веб-сервисов Emex (Эмекс) необходимо указать следующие параметры:

- *логин* – логин на сайте emex.ru,
- *пароль* – пароль на сайте.

## Опции методов

Опции методов используются как при поиске цен, так и при отправке заказа поставщику. По умолчанию используются опции, установленные в карточке прайс-листа. Если требуется, то при проценке или отправке заказа поставщику вручную, могут быть назначены собственные значения опций, необходимые в данный момент.

Опции методов настраиваются на вкладке "Опции методов".

В Веб-сервисах Emex (Эмекс) предусмотрены следующие опции:

| Опция | Значения | Описание |
| --- | --- | --- |
| **Использование замен** | - С заменами и аналогами (по умолчанию)<br>- Без замен и аналогов | Определяет выводить предложения в проценке с заменами и аналогами или без |
| **Фильтр по типу деталей** | - Не фильтровать (по умолчанию)<br>- Искомый номер и замены<br>- Искомый номер и аналоги | Позволяет установить фильтр по заменам или аналогам |
| **Мин. вероятность поставки** | Число | Позволяет не выводить предложения в проценке, у которых вероятность поставки ниже указанного в опции значения |
| **Мин. кол-во в наличии** | Число | Позволяет не выводить предложения в проценке, у которых количество в наличии ниже указанного в опции значения |
| **Макс. срок поставки** | Число | Позволяет не выводить предложения в проценке, у которых срок поставки превышает заданное в опции значение |
| **Макс. цена** | Число | Позволяет не выводить предложения в проценке, у которых цена превышает заданное в опции значение |
| **Макс. число предложений по одной детали** | Число | Позволяет не выводить предложения в проценке, у которых число предложений по одной детали превышает заданное в опции значение (лишние, т.е. более плохие, предложения будут отброшены) |
| **Тип доставки** | - Наземный (по умолчанию)<br>- Авиа | Определяет тип доставки |
| **Вид расчетов** | - Безналичный (по умолчанию)<br>- Наличный | Определяет способ расчета с поставщиком: наличными или по безналу |

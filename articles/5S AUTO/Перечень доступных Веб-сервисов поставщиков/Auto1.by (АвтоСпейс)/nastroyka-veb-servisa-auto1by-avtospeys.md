## Описание

Обработка предназначена для работы с Веб-сервисами компании **"АвтоСпейс"**  [https://auto1.by/help/api2](https://auto1.by/help/api2)

**Для использования Веб-сервисов "АвтоСпейс" необходимо:**

1. Быть зарегистрированным на сайте поставщика [https://auto1.by/](https://auto1.by/);
2. Обратиться к своему ответственному менеджеру или в ближайший из филиалов компании за получением дальнейших инструкций.

**Места использования Веб-сервисов:**

- Проценка;
- Отправка Веб-заказа поставщику ИЛИ размещение заказа в корзине поставщика.

После получения всех необходимых для подключения параметров выполняются следующие действия для Веб прайс-листа:

1. Заполнение параметров подключения (см. *Параметры подключения*).
2. Сохранение параметров подключения.
3. Обновление словарей сервиса с помощью соответствующей кнопки-ссылки.
4. Настройка опций методов (см. *Опции методов*).
5. Настройка параметров отправки заказа (см. [*Создание и настройка Веб прайс-листа→Настройка параметров для отправки заказа поставщику*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-отправки-заказа-поставщику)).
6. Настройка локальных прайс-листов, доступных для Веб-заказа (см. [*Создание и настройка Веб прайс-листа→Настройка параметров для формирования заказа поставщику из локальных прайс-листов*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-формирования-заказа-поставщику-из-локальных-прайс-листов)).
7. Сохранение всех изменений.

## Параметры подключения

Параметры подключения к Веб-сервису поставщика настраиваются на вкладке "Параметры сервиса".

Для подключения Веб-сервисов Auto1.by (АвтоСпейс) необходимо указать следующие параметры:

- *Логин/e-mail* – логин пользователя на сайте; для использования в обработчике желательно создать нового пользователя, чтобы избежать возможных пересечений при отправке корзины в заказ;
- *пароль* – пароль пользователя на сайте.

## Опции методов

Опции методов используются как при поиске цен, так и при отправке заказа поставщику. По умолчанию используются опции, установленные в карточке прайс-листа. Если требуется, то при проценке или отправке заказа поставщику вручную, могут быть назначены собственные значения опций, необходимые в данный момент.

Опции методов настраиваются на вкладке "Опции методов".

В Веб-сервисах Auto1.by (АвтоСпейс) предусмотрены следующие опции:

| Опция | Значения | Описание |
| --- | --- | --- |
| **Организация** | Из словаря | Организация, отгружающая товар, и тип заказа |
| **Способ получения** | - Доставка<br>- Самовывоз | Способ получения товаров |
| **Адрес доставки товара** | Из словаря | Адрес доставки товара |
| **Тип поиска** | - На любых складах (по умолчанию)<br>- Только в Автоспейс | Тип поиска товаров |
| **С учетом аналогов** | - С аналогами<br>- Без аналогов | Проценка с учетом аналогов или без |

## Описание

Обработчик предназначен для работы с Веб-сервисами компании **"М Партс"**: [https://v01.ru](https://v01.ru/).

Для использования Веб-сервисов MParts (М Партс) необходимо зарегистрироваться и авторизоваться на сайте компании [https://v01.ru](https://v01.ru/) для активации учетной записи.

Документация к API: [https://v01.ru/api/devinsight/documentation/](https://v01.ru/api/devinsight/documentation/).

**Места использования Веб-сервисов:**

- Проценка;
- Отправка Веб-заказа поставщику.
- Формирование заказа через Веб-сервис из локальных прайс-листов.

После получения всех необходимых для подключения параметров выполняются следующие действия для Веб прайс-листа:

1. Заполнение параметров подключения (см. *Параметры подключения*).
2. Сохранение параметров подключения.
3. Обновить словари сервиса путем нажатия кнопки-ссылки "Обновить словари для заказа".
4. Настройка опций методов (см. *Опции методов*).
5. Настройка параметров проценки (см.* [Создание и настройка Веб прайс-листа→Настройка параметров для проценки](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-проценки)*).
6. Настройка параметров отправки заказа (см. *[Создание и настройка Веб прайс-листа→Настройка параметров для отправки заказа поставщику](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-отправки-заказа-поставщику)*).
7. Настройка локальных прайс-листов, доступных для Веб-заказа (см. [*Создание и настройка Веб прайс-листа→Настройка параметров для формирования заказа поставщику из локальных прайс-листов*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-формирования-заказа-поставщику-из-локальных-прайс-листов)).
8. Сохранение всех изменений.

## Параметры подключения

Параметры подключения к Веб-сервису поставщика настраиваются на вкладке "Параметры сервиса".

Для подключения Веб-сервисов MParts (М Партс) необходимо указать следующие параметры:

- *Логин* - логин на сайте,
- *Пароль* - пароль на сайте

## Опции методов

Опции методов используются как при поиске цен, так и при отправке заказа поставщику. По умолчанию используются опции, установленные в карточке прайс-листа. Если требуется, то при проценке или отправке заказа поставщику вручную, могут быть назначены собственные значения опций, необходимые в данный момент.

Опции методов настраиваются на вкладке "Опции методов".

В Веб-сервисах MParts (М Партс) предусмотрены следующие опции:

| Опция | Значения | Описание |
| --- | --- | --- |
| **Использовать онлайн-склады** | - Не использовать<br>- Использовать (по умолчанию) | Если выключено, то в выдачу проценки не будут попадать предложения с online-складов, что позволит увеличить скорость ответа |
| **Способ оплаты** | Из словаря сервиса | Идентификатор способа оплаты необходим при отправке заказа (при включенной опции на сайте поставщика "Корзина: показывать способ оплаты") |
| **Способ доставки** | Из словаря сервиса | Идентификатор способа доставки необходим при отправке заказа (при включенной опции на сайте поставщика "Корзина: показывать способ оплаты") |
| **Адрес доставки** | Из словаря сервиса | Идентификатор адреса доставки необходим при отправке заказа и выбора соответствующего способа доставки |
| **Офис самовывоза** | Из словаря сервиса | Идентификатор офиса самовывоза необходим при отправке заказа (при включенной опции на сайте поставщика "Заказы: показывать офисы при выборе самовывоза") |
| **Комментарий** | Строка | Комментарий к заказу |

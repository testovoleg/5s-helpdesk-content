## Описание

Обработчик предназначен для работы с Веб-сервисами поставщиков, которые используют платформу **"Tradesoft.ru"**.

**Для использования Веб-сервисов необходимо:**

1. Узнать у поставщика работает ли он на платформе "Tradesoft.ru".
2. Уточнить параметры подключения к сервису у поставщика и запросить разрешение на использование (ваш IP адрес должен быть в списке разрешенных).

**Места использования Веб-сервисов:**

- Проценка.

После получения всех необходимых для подключения параметров выполняются следующие действия для Веб прайс-листа:

1. Заполнение параметров подключения (см. *Параметры подключения*).
2. Сохранение параметров подключения.
3. Обновление словарей заказа с помощью кнопок-ссылок "Обновить доступных поставщиков" и "Обновить доступные опции поставщика".
4. Настройка опций методов (см. *Опции методов*).
5. Настройка параметров проценки (см. [*Создание и настройка Веб прайс-листа→Настройка параметров для проценки*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-проценки)).
6. Сохранение всех изменений.

## Параметры подключения

Параметры подключения к Веб-сервисам поставщика настраиваются на вкладке "Параметры сервиса".

Для подключения необходимо указать следующие параметры:

- *сервер* – адрес сервиса (по умолчанию service.tradesoft.ru),
- *логин* – Ваш логин на сайте tradesoft.ru,
- *пароль* – Ваш пароль на сайте tradesoft.ru.

## Опции методов

Опции методов используются при поиске цен. По умолчанию используются опции, установленные в карточке прайс-листа. Если требуется, то при проценке могут быть назначены собственные значения опций, необходимые в данный момент.

Опции методов настраиваются на вкладке "Опции методов".

В Веб-сервисах через платформу "Tradesoft.ru" предусмотрены следующие опции:

| Опция | Значения | Описание |
| --- | --- | --- |
| **Поставщик (provider)** | Из словаря сервиса | Код поставщика в системе Tradesoft.ru |
| **Логин** | Строка | Логин на сайте поставщика |
| **Пароль** | Строка | Пароль на сайте поставщика |
| **Лимит времени на ответ** | Выбор значения от 5 сек до 50 сек | Лимит времени в секундах на получение данных от поставщика. Не обязательный параметр, регулируется в интервале от 1 до 50 (по умолчанию 10 сек). |

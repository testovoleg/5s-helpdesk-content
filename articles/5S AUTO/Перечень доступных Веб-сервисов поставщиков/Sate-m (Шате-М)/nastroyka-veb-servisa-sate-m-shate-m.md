## Описание

Обработчик предназначен для работы с Веб-сервисами компании **"Шате-М"**.

Описание API:

- [https://api.shate-m.ru/swagger/index.html](https://api.shate-m.ru/swagger/index.html)
- [https://api-doc.shate-m.ru](https://api-doc.shate-m.ru/)

**Для использования Веб-сервисов Sate-m (Шате-М) необходимо:**

Быть зарегистрированным на сайте поставщика (shate-m.ru).

**Места использования Веб-сервисов:**

- Проценка;
- Оформление заказа;
- Размещение заказа у поставщика.

После получения всех необходимых для подключения параметров выполняются следующие действия для Веб прайс-листа:

1. Заполнение параметров подключения (см. *[Параметры подключения](#параметры-подключения)).*
2. Сохранение параметров подключения.
3. Проверка соединения путем нажатия кнопки-ссылки "Проверить авторизацию".
4. Настройка опций методов (см. *[Опции методов](#опции-методов)).*
5. Настройка параметров проценки (см. *[Создание и настройка Веб прайс-листа → Настройка параметров для проценки](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-проценки)).*
6. Настройка параметров для отправки заказа поставщику (см. [*Создание и настройка Веб прайс-листа → Настройка параметров для отправки заказа поставщику*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-отправки-заказа-поставщику)*);*
7. Сохранение всех изменений.

## Параметры подключения

Параметры подключения к Веб-сервису поставщика настраиваются на вкладке "Параметры сервиса".

Для подключения Веб-сервисов Sate-m (Шате-М) необходимо указать следующие параметры:

- *сервер* – адрес сервиса,
- *логин* – логин от учетной записи на сайте,
- *пароль* – пароль от учетной записи на сайте.

## Опции методов

Опции методов используются как при поиске цен, так и при отправке заказа поставщику. По умолчанию используются опции, установленные в карточке прайс-листа. Если требуется, то при проценке или отправке заказа поставщику вручную, могут быть назначены собственные значения опций, необходимые в данный момент.

Опции методов настраиваются на вкладке "Опции методов".

В Веб-сервисах Sate-m (Шате-М) предусмотрены следующие опции:

| Опция | Значения | Описание |
| --- | --- | --- |
| **С учетом аналогов** | ● С аналогами (по умолчанию);<br>● Без аналогов | Определяет выводить предложения в проценке с аналогами или без |
| **Адрес доставки** | Выбор значения из словаря сервиса "Адреса доставки" | Идентификатор адреса доставки. Должен быть указан Тип отгрузки - "Доставка". Для размещения заказа на самовывоз адрес доставки должен остаться пустым |
| **Договор заказа** | Выбор значения из словаря сервиса "Договоры" | Идентификатор договора, по которому оформляется заказ. Если код группы договора == НАЛ или ЭКВАИР или МАГ, то поля ФИО и ТЕЛЕФОН обязательны к заполнению |
| **ФИО** | Строка | Контактное лицо по заказу. Обязательно к заполнению для группы договоров == НАЛ или ЭКВАИР или МАГ |
| **Телефон** | Строка | Телефон контактного лица. Обязательно к заполнению для группы договоров == НАЛ или ЭКВАИР или МАГ |

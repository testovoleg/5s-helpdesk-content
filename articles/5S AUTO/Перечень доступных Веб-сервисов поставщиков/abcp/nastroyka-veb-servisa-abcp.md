## Описание

Обработчик предназначен для работы с Веб-сервисами поставщиков, которые используют платформу **"abcp.ru"**.

Документация к API находится по адресу [http://docs.abcp.ru/wiki/API](http://docs.abcp.ru/wiki/API).

**Для использования Веб-сервисов необходимо:**

1. Узнать у поставщика работает ли он на платформе "abcp.ru".
2. Уточнить параметры подключения к сервису у поставщика и запросить разрешение на использование (ваш IP адрес должен быть в списке разрешенных).

**Места использования Веб-сервисов:**

- Проценка;
- Отправка Веб-заказа поставщику.

После получения всех необходимых для подключения параметров выполняются следующие действия для Веб прайс-листа:

1. Заполнение параметров подключения (см. *[Параметры подключения](https://5systems.zendesk.com/hc/ru/articles/4405588985361#h_01FCZABW1P9ABJE63BGR6JT1VW)*).
2. Сохранение параметров подключения.
3. Обновление словарей заказа с помощью кнопки-ссылки "Обновить словари для заказа".
4. Настройка опций методов (см. *[Опции методов](https://5systems.zendesk.com/hc/ru/articles/4405588985361#h_01FCZAC0TPA2VC3AN61HYZKWJR)*).
5. Настройка параметров проценки (см. [*Создание и настройка Веб прайс-листа→*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md)[*Настройка параметров для проценки*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-проценки)).
6. Настройка параметров отправки заказа (см. *[Создание и настройка Веб прайс-листа→Настройка параметров для отправки заказа поставщику](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-отправки-заказа-поставщику)*).
7. Сохранение всех изменений.

## Параметры подключения

Параметры подключения к Веб-сервисам поставщика настраиваются на вкладке "Параметры сервиса".

Для подключения необходимо указать следующие параметры:

- сервер – адрес сервиса: *<КодСайта>.public.api.abcp.ru*,
- логин,
- пароль.

## Опции методов

Опции методов используются как при поиске цен, так и при отправке заказа поставщику. По умолчанию используются опции, установленные в карточке прайс-листа. Если требуется, то при проценке или отправке заказа поставщику вручную, могут быть назначены собственные значения опций, необходимые в данный момент.

Опции методов настраиваются на вкладке "Опции методов".

В Веб-сервисах через платформу "abcp.ru" предусмотрены следующие опции:

| Опция | Значения | Описание |
| --- | --- | --- |
| **Использовать онлайн-склады** | - Не использовать (по умолчанию)<br>- Использовать | Включает или отключает попадание в выдачу результатов поиска цен деталей с online-складов (если выключено – увеличивается скорость ответа) |
| **Отключить фильтры** | - Не отключать (по умолчанию)<br>- Отключить | Отключает фильтры online поставщиков |
| **Исключить поиск по аналогам** | - Не исключать (по умолчанию)<br>- Исключить | Исключает поиск по аналогам |
| **Способ оплаты** | Из словаря сервиса | Идентификатор способа оплаты необходим при отправке заказа (при включенной опции "Корзина: показывать способ оплаты") |
| **Способ доставки** | Из словаря сервиса | Идентификатор способа доставки необходим при отправке заказа (при включенной опции "Корзина: показывать типы доставки") |
| **Адрес доставки** | Из словаря сервиса | Идентификатор адреса доставки – необходим при отправке заказа |
| **Офис самовывоза** | Из словаря сервиса | Идентификатор офиса самовывоза необходим при отправке заказа (при включенной опции "Заказы: показывать офисы при выборе самовывоза") |
| **Комментарий** | Строка | Комментарий к заказу |

## Описание

Обработчик предназначен для работы с Веб-сервисами компании **"ТИСС"** [http://api.tmparts.ru/](http://api.tmparts.ru/).

**Для использования Веб-сервисов Tmparts (ТИСС) необходимо:**

1. Быть клиентом компании более 2-х месяцев и с оборотом не менее 10 т.р. в месяц.
2. Направить заявку на подключение к api.tmparts.ru по адресу: [api@tpm.ru](mailto:api@tpm.ru).

**Места использования Веб-сервисов:**

- Проценка;
- Отправка Веб-заказа поставщику.
- Формирование заказа через Веб-сервис из локальных прайс-листов.

После получения всех необходимых для подключения параметров выполняются следующие действия для Веб прайс-листа:

1. Заполнение параметров подключения (см. *Параметры подключения*).
2. Сохранение параметров подключения.
3. Обновить словари сервиса путем нажатия кнопок-ссылок "Обновить Договоры клиента" и "Обновить Адреса доставки".
4. Синхронизировать производителей путем нажатия кнопки-ссылки "Синхронизировать производителей"
5. Настройка опций методов (см. *Опции методов*).
6. Настройка параметров проценки (см. [*Создание и настройка Веб прайс-листа→Настройка параметров для проценки*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-проценки)).
7. Настройка параметров отправки заказа (см. [*Создание и настройка Веб прайс-листа→Настройка параметров для отправки заказа поставщику*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-отправки-заказа-поставщику)).
8. Настройка локальных прайс-листов, доступных для Веб-заказа (см. *[Создание и настройка Веб прайс-листа→Настройка параметров для формирования заказа поставщику из локальных прайс-листов](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-формирования-заказа-поставщику-из-локальных-прайс-листов)*).
9. Сохранение всех изменений.

## Параметры подключения

Параметры подключения к Веб-сервису поставщика настраиваются на вкладке "Параметры сервиса".

Для подключения Веб-сервисов Tmparts (ТИСС) необходимо указать следующие параметры:

- *сервер* - адрес сервиса,
- *ключ доступа* - ключ доступа, полученный на странице [http://api.tmparts.ru/GetApiKey](http://api.tmparts.ru/GetApiKey).

## Опции методов

Опции методов используются как при поиске цен, так и при отправке заказа поставщику. По умолчанию используются опции, установленные в карточке прайс-листа. Если требуется, то при проценке или отправке заказа поставщику вручную, могут быть назначены собственные значения опций, необходимые в данный момент.

Опции методов настраиваются на вкладке "Опции методов".

В Веб-сервисах Tmparts (ТИСС) предусмотрены следующие опции:

| Опция | Значения | Описание |
| --- | --- | --- |
| **Договор** | Из словаря сервиса | Определяет договор, по которому будут оформляться заказы |
| **Адрес доставки** | Из словаря сервиса | Определяет адрес доставки заказа |
| **Вид поиска** | - Из наличия и под заказ (по умолчанию)<br>- С основного склада клиента<br>- Только товар в наличии | Определяет какие предложения выводить в проценке |
| **При увеличении цены** | - Соглашаться (по умолчанию)<br>- Исключать из заказа | Определяет согласиться с увеличением цены или исключить такие позиции из заказа |
| **При увеличении срока доставки** | - Соглашаться<br>- Исключать из заказа (по умолчанию) | Определяет согласиться с увеличением срока доставки или исключить такие позиции из заказа |
| **При уменьшении количества** | - Соглашаться<br>- Исключать из заказа (по умолчанию) | Определяет согласиться с уменьшением количества или исключить такие позиции из заказа. Количество в заказе может автоматически уменьшиться до кратного значения минимальной партии товара. |
| **При исключении позиций** | - Создавать<br>- Не создавать (по умолчанию) | При наличии отмененных позиций определяет создавать ли новый заказ или нет |
| **Тестовый режим работы** | - Тестовый режим (по умолчанию)<br>- Обычный режим | Определяет режим работы с сервисом. В тестовом режиме заказы будут автоматически отменяться при обработке сервисом. |
| **Задержка запросов (мс)** | Число | Требуемая задержка между обращениями к сервису в миллисекундах (сервис запрещает делать больше одного запроса в секунду) |

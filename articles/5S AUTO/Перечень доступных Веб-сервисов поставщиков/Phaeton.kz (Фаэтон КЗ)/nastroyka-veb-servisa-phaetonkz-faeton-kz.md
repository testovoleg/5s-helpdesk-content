## Описание

Обработчик предназначен для работы с клиентским API сайта shop.phaeton.kz ([http://api.phaeton.kz/](http://api.phaeton.kz/)).

**Для использования Веб-сервисов Phaeton.kz (Фаэтон КЗ) необходимо:**

1. Быть зарегистрированным на сайте shop.phaeton.kz.
2. Запросить у закрепленного за вами менеджера доступ к Веб-сервисам. Для этого необходимо предоставить IP-адрес, с которого вы будете производить подключение, и имя контрагента с сайта shop.phaeton.kz. В итоге менеджер должен предоставить UserGuid и ApiKey необходимые для вызова API методов (указываются в параметрах подключения).

   **Места использования Веб-сервисов:**

- Проценка;

  После получения всех необходимых для подключения параметров выполняются следующие действия для Веб прайс-листа:

1. Заполнение параметров подключения (см. *Параметры подключения*).
2. Сохранение параметров подключения.
3. Получение списка контрагентов по кнопке-ссылке "Получить список контрагентов".
4. Настройка опций методов (см. *Опции методов*).
5. Настройка параметров проценки (см. [*Создание и настройка Веб прайс-листа→Настройка параметров для проценки*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-проценки)).
6. Сохранение всех изменений.

## Параметры подключения

Параметры подключения к Веб-сервису поставщика настраиваются на вкладке "Параметры сервиса".

Для подключения Веб-сервисов Phaeton.kz (Фаэтон КЗ) необходимо указать следующие параметры:

- *UserGuid* - идентификатор пользователя, предоставленный менеджером сайта,
- *ApiKey* - ключ, необходимый для доступа к сервисам.

## Опции методов

Опции методов используются как при поиске цен, так и при отправке заказа поставщику. По умолчанию используются опции, установленные в карточке прайс-листа. Если требуется, то при проценке или отправке заказа поставщику вручную, могут быть назначены собственные значения опций, необходимые в данный момент.

Опции методов настраиваются на вкладке "Опции методов".

В Веб-сервисах Phaeton.kz (Фаэтон КЗ) предусмотрены следующие опции:

| Опция | Значения | Описание |
| --- | --- | --- |
| **С учетом аналогов** | - С аналогами (по умолчанию)<br>- Без аналогов | Определяет показывать ли предложения в проценке с аналогами или без |
| **Наличие Phaeton** | - Да (по умолчанию)<br>- Нет | При включении будут искаться предложения в наличии на складах Phaeton |
| **Локальные поставщики** | - Да (по умолчанию)<br>- Нет | При включении будут искаться предложения от локальных поставщиков |
| **Удаленные поставщики** | - Да<br>- Нет (по умолчанию) | При включении будут искаться предложения от удаленных поставщиков |
| **Контрагент** | Из словаря сервиса | Контрагент для оформления заказа |
| **Игнорировать ошибки** | - Да<br>- Нет (по умолчанию) | Если параметр задан в Да, будут игнорироваться ошибки об изменении цены, и заказ будет сформирован в любом случае (только для товаров со складов Phaeton) |

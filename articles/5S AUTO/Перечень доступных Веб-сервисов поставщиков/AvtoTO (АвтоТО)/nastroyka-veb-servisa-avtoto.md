## Описание

Обработчик предназначен для работы с Веб-сервисами компании **AvtoTO (АвтоТО)**: [https://www.avtoto.ru](https://www.avtoto.ru/).

Описание: [https://old.avtoto.ru/services/search/docs/](https://old.avtoto.ru/services/search/docs/)

**Для использования Веб-сервисов AvtoTO (АвтоТО) необходимо:**

1. Заключить договор поставки. Для этого нужно обратиться в клиентский отдел компании AvtoTO (АвтоТО) любым удобным способом. Дальнейшие действия возможны только после подписания договора.
2. Активировать сервис и добавить IP адрес своего сайта на странице "настройка веб-сервиса".
3. В карточке прайс-листа веб-сервиса ввести логин, пароль (как при авторизации на сайте) и номер клиента (номер указан в разделе общая информация).

   **Места использования Веб-сервисов:**

- Проценка;
- Отправка Веб-заказа поставщику ИЛИ размещение заказа в корзине поставщика;
- Формирование заказа через Веб-сервис из локальных прайс-листов.

  После получения всех необходимых для подключения параметров выполняются следующие действия для Веб прайс-листа:

1. Заполнение параметров подключения (см. *Параметры подключения*).
2. Сохранение параметров подключения.
3. Настройка опций методов (см. *Опции методов*).
4. Настройка параметров проценки (см. [*Создание и настройка Веб прайс-листа→Настройка параметров для проценки*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-проценки)).
5. Настройка параметров отправки заказа (см. *[Создание и настройка Веб прайс-листа→Настройка параметров для отправки заказа поставщику](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-отправки-заказа-поставщику)*).
6. Сохранение всех изменений.

## Параметры подключения

Параметры подключения к Веб-сервису поставщика настраиваются на вкладке "Параметры сервиса".

Для подключения Веб-сервисов AvtoTO (АвтоТО) необходимо указать следующие параметры:

- *номер клиента* – номер указан в разделе "Общая информация",
- *логин* – логин пользователя на сайте,
- *пароль* – пароль пользователя на сайте.

## Опции методов

Опции методов используются при поиске цен. По умолчанию используются опции, установленные в карточке прайс-листа. Если требуется, то при проценке могут быть назначены собственные значения опций, необходимые в данный момент.

Опции методов настраиваются на вкладке "Опции методов".

В Веб-сервисах AvtoTO (АвтоТО) предусмотрены следующие опции:

| Опция | Значения | Описание |
| --- | --- | --- |
| **С учетом аналогов** | - С аналогами (по умолчанию)<br>- Без аналогов | Определяет, отображать ли аналоги при поиске предложений |

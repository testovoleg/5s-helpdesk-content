## Описание

Обработка предназначена для работы с клиентским API [www.abs-auto.ru](http://www.abs-auto.ru/) ([http://api.abs-auto.ru/](http://api.abs-auto.ru/)).

**Для использования Веб-сервисов "Абс-Авто" необходимо:**

- Быть зарегистрированным на сайте поставщика.

**Места использования Веб-сервисов:**

- Проценка.

После получения всех необходимых для подключения параметров выполняются следующие действия для Веб прайс-листа:

1. Заполнение параметров подключения (см. *Параметры подключения*).
2. Сохранение параметров подключения.
3. Обновление словарей сервиса с помощью соответствующей кнопки-ссылки.
4. Настройка опций методов (см. *Опции методов*).
5. Настройка параметров отправки заказа (см. *[Создание и настройка Веб прайс-листа→Настройка параметров для отправки заказа поставщику](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-отправки-заказа-поставщику)*).
6. Настройка локальных прайс-листов, доступных для Веб-заказа (см. [*Создание и настройка Веб прайс-листа→Настройка параметров для формирования заказа поставщику из локальных прайс-листов*](../../Склад%20и%20запчасти/Создание%20и%20настройка%20Веб%20прайс-листа/sozdanie-i-nastroyka-veb-prays-lista.md#настройка-параметров-для-формирования-заказа-поставщику-из-локальных-прайс-листов)).
7. Сохранение всех изменений.

## Параметры подключения

Параметры подключения к Веб-сервису поставщика настраиваются на вкладке "Параметры сервиса".

Для подключения Веб-сервисов AbsAuto (Абс-Авто) необходимо указать следующие параметры:

- *Логин* – логин пользователя на сайте;
- *пароль* – пароль на сайте.

## Опции методов

Опции методов используются при поиске цен. По умолчанию используются опции, установленные в карточке прайс-листа. Если требуется, то при проценке могут быть назначены собственные значения опций, необходимые в данный момент.

Опции методов настраиваются на вкладке "Опции методов".

В Веб-сервисах Auto1.by (АвтоСпейс) предусмотрены следующие опции:

| Опция | Значения | Описание |
| --- | --- | --- |
| **С учетом аналогов** | - Искать аналоги (по умолчанию)<br>- Без аналогов | Проценка с учетом кроссов (аналогов) или без |
| **Договор** | Из словаря | Идентификатор текущего договора с поставщиком |
| **Адрес доставки** | Из словаря | Адрес доставки товара |
| **Способ доставки** | Из словаря | Способ доставки товара |

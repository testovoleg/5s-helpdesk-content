## Введение

Согласно логике системы «Честный Знак» есть 2 основных способа выбытия товаров с кодом маркировки:

1. **Продажа через ККМ.** При пробитии чека ККМ товар автоматически выводится из оборота, сведения передаются оператором фискальных данных (ОФД) в систему «Честный Знак» в онлайн-режиме по каждой реализованной товарной единице.
2. **Передача через ЭДО.** В случае реализации маркированного товара другому участнику оборота код маркировки выводится с баланса продавца и передается через систему ЭДО другому собственнику — при этом товар не выбывает из оборота.

В остальных случаях продавец должен самостоятельно отражать выбытие кодов маркировки из оборота. К таким случаям относятся:

1. Списание на собственные или производственные нужды компании — в случае использования режима печати чека «одной строкой» или включения маркированных товаров в состав услуг.
2. Реализация по безналичному расчету покупателю, который не является участником оборота маркированных товаров.
3. Продажа без отражения в фискальном чеке ККМ и без передачи по ЭДО.
4. Нечитаемый код маркировки на упаковке.
5. Утилизация маркированного товара (например, испорченного или с истекшим сроком годности), утрата или уничтожение товара.

При выводе товаров из оборота на перечисленных основаниях сведения должны быть переданы в систему не позднее **3 рабочих дней**, следующих за днем выбытия товаров из оборота (в соответствии с [ППРФ от 30.11.2024 №1683](https://www.consultant.ru/), п. 112-113).

Для отражения таких операций во внутреннем учете, а также для автоматизации отражения выбытия маркированных товаров из оборота в системе «Честный Знак» в программе предусмотрен документ **«Вывод из оборота»**.

## Варианты выбытия из оборота кодов маркировки

### 1. Выбытие при продаже

#### Особенности вывода из оборота кодов маркировки при продаже

В случае выбытия маркированных товаров при продаже, если это не было отражено в электронном УПД или чеке, переданном в ОФД, необходимо передать сведения на портал ГИС МТ напрямую не позже 3 дней со дня продажи.

Также передача сведений о выбытии маркированного товара потребуется, если компания является участником оборота, но не продает товар, а включает его в состав услуг. Например, если автосервис работает на патентной системе, позволяющей производить ремонт и ТО автомобилей, и имеет право пробивать чеки только на услуги. В этом случае выбытие маркированных товаров не отражается в чеках ККМ или в электронном УПД.

Создание документов вывода из оборота в программе предусмотрено путем ввода на основании **Реализации товаров** или **Заказ-наряда**:

![Ввод на основании](attachments/01-Маркировка_Вывод_из_оборота_01-Ввод_на_основании-1.png)

Есть возможность настроить автоматическое создание документов вывода из оборота при закрытии Заказ-наряда или Реализации товаров. Документ «Вывод из оборота» будет создаваться программой в следующих случаях:

1. В документе продажи указана причина выбытия (см. ниже).
2. Маркированный товар включается в стоимость услуги в заказ-наряде, т.е. если к организации привязана касса с режимом пробития чека «Одной строкой» либо «Стоимость товаров включена в работу».

Созданный вручную или автоматически документ вывода маркировок из оборота затем требуется отправить в «Честный Знак» через API либо через выгрузку файла для списания маркированных товаров с баланса компании — см. ниже.

> **Примечание.** При автоматическом создании документов выбытия маркированных товаров в эти документы не попадают маркировки по товарам с **частичным выбытием**. В случае продажи, например, моторного масла на розлив из бочки, выводить из оборота следует всю бочку при продаже последней порции товара (при достижении минимального остатка, не подлежащего дальнейшей реализации). Требуется создать вручную документ вывода из оборота, отсканировать код маркировки на бочке, затем отправить данные в «Честный Знак».

#### Причины вывода в документе продажи

> Доступно начиная с релиза 2.8.3.18, обновлено в релизе 2.8.3.42

Для того, чтобы в программе автоматически создавались документы «Вывод из оборота», в документах продажи должна быть заполнена причина выбытия.

В Заказ-наряде или Реализации товаров на вкладке **«Дополнительно»** следует выбрать из списка нужную причину вывода — «Розничная продажа» или «Использование для собственных нужд» — и записать документ:

![Причина вывода в документе продажи](attachments/02-Маркировка_Вывод_из_оборота_34-Причина_вывода_Розничная_продажа-1.png)

> **Примечание.** В документе на вкладке «Дополнительно» также справочно выводится информация, является ли контрагент участником оборота маркированных товаров — при условии активной интеграции с «Честным Знаком» и корректно заполненного ИНН в карточке контрагента.

При проведении документа продажи на его основании автоматически создается документ «Вывод из оборота кодов маркировки», в который переносится причина выбытия из исходного документа:

![Документ Вывод из оборота на основании](attachments/03-Маркировка_34-Вывод_из_оборота_На_основании-1_0.png)

Есть возможность настроить автоматическое заполнение причины вывода из оборота в документах продажи при реализации данному контрагенту — для этого следует в карточке контрагента на вкладке **«Прочее»** указать нужную причину по умолчанию:

![Участник оборота в карточке контрагента](attachments/04-Маркировка_Вывод_из_оборота_31-ИНН_Участника_в_контрагенте_new-1.png)

При создании новых документов продажи для этого контрагента (Реализация, Заказ-наряд) причина вывода кодов маркировки из оборота будет подтягиваться автоматически.

### 2. Выбытие по иным причинам

Маркированный товар также необходимо выводить из оборота в случаях уничтожения, утилизации, утраты, истечения срока годности и в прочих ситуациях — для этого следует создавать документы «Вывод из оборота» с использованием причин: «Утрата или повреждение», «Конфискация» и т.д.

Возможные причины выбытия маркированных товаров:

1. В результате инвентаризации кодов маркировки выявлены расхождения между данными во внутренней учетной системе и информацией в системе «Честный знак», например:
   - в переходный период введения учета маркировки накопились коды, которые не были выведены из оборота автоматически через кассу ККМ или переданы новым собственникам через ЭДО;
   - не совпадают статусы кодов маркировки (например, в «Честном знаке» статус «Продан», а во внутреннем учете — «В обороте», или наоборот);
   - в результате инвентаризации товаров выявлены расхождения (товар утерян, украден или испорчен) — следует выявить коды, которые физически отсутствуют, но числятся в обороте, и оформить их списание.
2. Списание на собственные нужды компании — сначала требуется отразить списание товара во внутреннем учете и оформить бухгалтерские проводки, затем оформить «Вывод из оборота» с указанием причины «Использование для собственных нужд».

В подобных случаях рекомендуется оформить внутренний документ в зависимости от причины выбытия (списание товаров, инвентаризация, акт списания, акт утилизации) и указать данный документ в «Выводе из оборота». Затем следует передать сведения в «Честный Знак» через API либо через выгрузку файла.

## Обновление связанных документов

Если документ «Заказ-наряд» или «Реализация товаров» уже закрыт, и по нему есть введенные на основании документы «Вывод из оборота», то может потребоваться обновление документов для выгрузки данных в «Честный Знак». Без обновления документов возможна ошибка при выгрузке.

Для этого необходимо перезаписать исходный документ продажи и в появившемся окне обновления документов нажать кнопку **«ОК»**:

![Окно обновления документов](attachments/05-Маркировка_Вывод_из_оборота_28-Обновление_документов_1-1.png)

При этом система откроет связанные документы «Вывод из оборота» (их может быть несколько — по разным товарным группам):

![Связанные документы Вывод из оборота](attachments/06-Маркировка_Вывод_из_оборота_29-Обновление_документов_Вывод_из_оборота_1-1.png)

Следует пересохранить каждый документ нажатием на кнопку **«ОК»**.

## Выгрузка документа «Вывод из оборота» в систему «Честный Знак»

Документы «Вывод из оборота», сформированные в программе, **не отправляются в ГИС МТ автоматически**.

Выгружать их из 5S AUTO в систему «Честный Знак» можно одним из следующих способов:

1. Выгрузка через API с подписанием ключом через браузер
2. Выгрузка через API с локальной подписью через КриптоПро
3. Выгрузка в файл и загрузка в ЛК «Честного Знака»

Есть возможность выгружать как отдельный документ, так и несколько документов сразу.

После успешного вывода из оборота статус маркированного товара должен измениться на **«Выбыл»**.

### 1. Выгрузка отдельного документа

#### 1) Выгрузка через API с подписанием ключом через браузер

Для отправки документа «Вывод из оборота» в «Честный Знак» через API требуется подписание ключом.

В документе нажать кнопку **«Выгрузить → API, подписать в браузере»**:

![Выгрузить API подписать в браузере](attachments/07-Маркировка_Вывод_из_оборота_01-Способы_1-1.png)

![Окно создания документа по товарной группе](attachments/08-Маркировка_Вывод_из_оборота_02-Отправка_с_подписанием_ключом_1-1.png)

Нажать кнопку **«Скопировать»** и вставить полученную ссылку в адресную строку браузера (рекомендуется использовать Яндекс Браузер) — производится переход к авторизации в 5S Cloud. Необходимо ввести учетные данные пользователя 5S Cloud:

![Авторизация в 5S Cloud](attachments/09-Маркировка_Вывод_из_оборота_03-Переход_по_ссылке_Авторизация_1.png)

После успешной авторизации открывается приложение 5S Sign. На странице «Создание подписи» выбрать сертификат и нажать кнопку **«Создать подпись»**:

![Создание подписи в 5S Sign](attachments/10-Маркировка_Вывод_из_оборота_04-Переход_по_ссылке_Подписание_ключом_Пример-1-1.png)

Создается подпись, отображается статус «Создана» и уведомление «Подпись сохранена»:

![Подпись сохранена](attachments/11-Маркировка_Вывод_из_оборота_05-Переход_по_ссылке_Подписано_Пример-1-1.png)

После этого можно вернуться в программу и закрыть окно получения ссылки. В программе появляется служебное сообщение «Подпись для отправки документов получена» и уведомление «Данные успешно отправлены в личный кабинет Честного знака»:

![Свойства выгруженного документа](attachments/13-Маркировка_Вывод_из_оборота_07-Свойство_Выгружен_1-1.png)

![Документ в ЛК обработан успешно](attachments/16-Маркировка_Вывод_из_оборота_10-Документ_в_ЛК.png)

#### 2) Выгрузка через API с подписанием через КриптоПро в программе

Данный способ — также выгрузка через API, но с прямым подписанием через программу, минуя переход по ссылке в браузере.

Требуется предварительная настройка — установка отпечатка сертификата. Для корректной работы должна быть установлена последняя версия КриптоПро. Также к компьютеру должен быть подключен носитель с сертификатом.

Для выгрузки с локальным подписанием нажать кнопку **«Выгрузить → API, подписать локально»**:

![Выгрузить API подписать локально](attachments/17-Маркировка_Вывод_из_оборота_35-Подпись_в_программе-1.png)

При первой попытке открывается обработка **«Установка данных о сертификате Честный Знак»**:

![Установка данных о сертификате](attachments/18-Маркировка_Вывод_из_оборота_36-Подпись_в_программе_Обработка_устновки_ключа_1.png)

Необходимо заполнить данные:

- **Пользователь** — текущий пользователь, подтягивается автоматически
- **Организация** — подтягивается автоматически по пользователю
- **Сертификат** — выбрать сертификат из списка

После заполнения параметров нажать **«ОК»**.

После установки отпечатка сертификата для подписи и выгрузки достаточно нажимать **«Выгрузить → API, подписать локально»** без перехода в браузер. Проверить выгрузку можно в личном кабинете «Честного Знака».

### 2. Групповая выгрузка

Если требуется выгрузить сразу несколько документов «Вывод из оборота», предусмотрена групповая выгрузка через обработку **«API Честный знак»**.

Открыть обработку можно через меню: **Запчасти и склад → Продажи → Обработки → API Честный Знак**, вкладка **«Выводы из оборота»**:

![Обработка API Честный Знак в меню](attachments/28-Маркировка_Вывод_из_оборота_11-Выгрузка_через_обработку_В_меню-1.png)

Также вызвать обработку можно через форму списка документов вывода из оборота по кнопке **«Обработки → Выгрузка данных через API»**:

![Вызов обработки из списка документов](attachments/29-Маркировка_Вывод_из_оборота_11-Выгрузка_через_обработку_Вызов_через_список-1.png)

В таблицу выводятся все невыгруженные документы вывода из оборота:

![Список невыгруженных документов](attachments/30-Маркировка_Вывод_из_оборота_11-Выгрузка_через_обработку_new.png)

Необходимо выбрать организацию — при этом в таблице останутся только документы по данной организации:

![Отбор по организации](attachments/31-Маркировка_Вывод_из_оборота_12-Выгрузка_через_обработку_отбор_new-1.png)

Затем нажать кнопку **«Выгрузить»** и выбрать способ выгрузки:

![Способы групповой выгрузки](attachments/32-Маркировка_Вывод_из_оборота_12-Обработка_Способы_выгрузки-1.png)

#### Способы выгрузки

**1) Сводно выгрузить в файл** — формируются файлы с группировкой по товарным группам (количество файлов = количество товарных групп).

Для скачивания файлов последовательно выделить нужную строку и нажать **«Сохранить файл на диск»** либо **«Скопировать ссылку»**:

![Групповая выгрузка в файл](attachments/33-Маркировка_Вывод_из_оборота_13-Выгрузка_через_обработку_Файл_new-1.png)

Скачанные файлы нужно загрузить в ЛК «Честного Знака» (по аналогии с загрузкой файла по отдельному документу) и подтвердить загрузку вводом в программе идентификатора и даты документа по каждому файлу:

![Подтверждение групповой выгрузки](attachments/34-Маркировка_Вывод_из_оборота_17-Выгрузка_в_файл_Подтверждение_Групповая-1.png)

Также обработку групповой выгрузки в файл можно вызвать через форму списка документов «Вывод из оборота» — кнопка **«Обработки → Выгрузка данных в файл»**:

![Выгрузка данных в файл из списка](attachments/35-Маркировка_Вывод_из_оборота_25-Выгрузка_в_файл_Обработка-1.png)

В окне «Выгрузка вывода из оборота через файл в Честный Знак» выбрать организацию и нажать **«Выгрузить в файл»**. Будут последовательно созданы файлы по каждой товарной группе.

**2) Сводно подписать через браузер и выгрузить в API** — данные группируются по товарным группам и выгружаются в ЛК «Честного Знака». Требуется подписание ключом: получить ссылку, авторизоваться через 5S Cloud, в 5S Sign выбрать сертификат и создать подпись. Подробнее — см. выгрузку отдельного документа с подписанием через API.

**3) Подписать локально и выгрузить в API** — выгрузка через API с прямым подписанием в программе. Документы выгружаются последовательно. Требуется предварительная установка отпечатка сертификата, последняя версия КриптоПро и подключенный носитель с сертификатом.

Проверить выгрузку можно в личном кабинете «Честного Знака».

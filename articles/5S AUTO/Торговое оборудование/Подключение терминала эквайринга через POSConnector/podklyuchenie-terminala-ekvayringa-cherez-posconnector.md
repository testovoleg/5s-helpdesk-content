## Введение

В программе поддерживается подключение терминалов эквайринга через библиотеку ***POSConnector*** – подходит любой терминал, который работает через POSConnector, в том числе терминалы Альфа-Банка и ВТБ, включая линейку терминалов с биометрией. В программе модель называется ***«Эквайринг-терминал POSConnector»***.

> 🛠 Комментарий для черновика: *Привязки к банку в программе нет, банк определяется адресом процессинга в client.ini и TID; название банка в интерфейсе нигде не встречается. Биометрию из 1С не видно — чем покупатель подтверждает оплату, решает терминал. Перечень банков и поддержку биометрии подтвердить у того, кто проверял терминалы; переименовывать ли модель, чтобы было видно банк, — решение команды.*

> 🛠 Комментарий для черновика: *На терминалах каких банков подключение проверялось? Подтверждается ли поддержка терминалов с биометрией? Пока в тексте – по описанию релиза (Альфа-Банк, ВТБ, биометрия). (у разработчика (Катя) нет ответа на этот вопрос; задан повторно 01.10.2026, ждем ответа)*

> 🛠 Комментарий для черновика: *Переименовывать ли модель «Эквайринг-терминал POSConnector», чтобы в программе было видно банк? (у разработчика (Катя) нет ответа на этот вопрос; задан повторно 01.10.2026, ждем ответа)*

Оплата картой принимается во Фронте кассира в обычном порядке: программа передает терминалу сумму и тип операции, терминал проводит операцию в банке и возвращает код авторизации, номер ссылки (RRN), номер чека терминала и текст слипа. Фронт кассира печатает слип и пробивает фискальный чек.

В отличие от терминалов, которые подключаются через интеграцию «Альфа-Авто» (см. статью «[Подключение банковского терминала](../Подключение%20банковского%20терминала/podklyuchenie-bankovskogo-terminala.md)»), терминал POSConnector подключается через интеграцию «5S AUTO»: внешняя компонента для него не нужна, схему устройств обновлять не требуется.

Поддерживаемые операции: *оплата, возврат, отмена платежа,* проверка связи с процессингом при включении терминала и *сверка итогов* при закрытии смены.

## Подготовка к настройке

- На кассовом компьютере должна быть установлена ***библиотека POSConnector*** и зарегистрированы ее COM-объекты. Библиотека 32-разрядная, поэтому программа 1С на этом компьютере тоже должна быть *32-разрядной.*
- Адрес и порт процессинга задаются в файле *client.ini* рядом с библиотекой POSConnector – в программе они не настраиваются.
- Пинпад должен быть подключен к компьютеру.
- Банк должен выдать ***номер терминала (TID)*** – из банковских данных в программе указывается только он.
- Должен быть заполнен справочник ***«Типы платежных карт»:*** по нему Фронт кассира сверяет тип карты, выбранный кассиром.

> 🛠 Комментарий для черновика: *Кто устанавливает библиотеку POSConnector и настраивает client.ini (специалист банка, партнер по внедрению или клиент), разработчик не знает — это организационный вопрос, нужно согласовать и записать явно: от этого зависит, к кому обращаться при ошибках 22161 и 22162. COM-объекты: «POSConnectorInterface-posconlib» и «SAPacket-posconlib».*

Есть ли скриншоты из рабочей базы (мастер добавления оборудования, шаги 1–3; форма «Параметры драйвера» с заполненным TID; карточка рабочего места с реквизитом «Авторизатор»)? Откройте справочник ***«Оборудование»*** (*Администрирование → Сервис → Оборудование* или *Справочники → Розница и оборудование → Оборудование*, подробнее см. статью «[Справочник «Оборудование»](../Справочник%20Оборудование/spravochnik-oborudovanie.md)») и добавьте новый элемент – откроется *мастер добавления оборудования.*

(вопрос задан разработчику (Катя) 01.10.2026, ждем ответа)*

**1.** На *шаге 1* выберите интеграцию ***«5S AUTO»*** и нажмите *«Далее».*

> 🛠 Комментарий для черновика: *нужен скриншот — шаг 1 мастера с выбранной интеграцией «5S AUTO».*

**2.** На *шаге 2* выберите класс оборудования ***«Эквайринг-терминал»*** и нажмите *«Далее».*

**3.** На *шаге 3* выберите модель ***«Эквайринг-терминал POSConnector»*** и нажмите *«Далее»* – откроется карточка нового оборудования.

> 🛠 Комментарий для черновика: *нужны скриншоты — шаги 2 и 3 мастера (можно двумя картинками).*

**4.** Заполните наименование, при необходимости измените *таймаут ожидания результатов выполнения команды* (если значение не заполнено или меньше 5 секунд, используется 90 секунд) и запишите карточку. Идентификатор устройства (GUID) заполнится автоматически.

**5.** Нажмите ***«Оборудование → Настроить параметры»***, заполните *«Номер терминала (TID)»* и при необходимости другие параметры (см. [ниже](#параметры-драйвера)), нажмите *«ОК»* и запишите карточку.

> 🛠 Комментарий для черновика: *нужен скриншот — форма «Параметры драйвера» с заполненным TID.*

**6.** Нажмите ***«Оборудование → Включить».*** Программа проверит связь с процессингом – если связь есть, терминал перейдет в состояние *«Включено».*

В меню «Оборудование» для терминала работают команды *«Включить», «Выключить», «Настроить параметры»* и *«Обновить состояние».* Остальные команды («Товары», «Загрузить», «Обновить схему устройств») для терминала не используются.

### Параметры драйвера

Форма ***«Параметры драйвера»*** открывается командой *«Оборудование → Настроить параметры»* в карточке или в списке оборудования:

- ***Номер терминала (TID)*** – идентификатор терминала, выданный банком. Обязательный параметр – без него терминал не включится;
- ***Печать квитанций на пинпаде*** – если *«Да»*, слип печатает сам пинпад, а не фискальный регистратор или принтер чеков. По умолчанию *«Нет»*;
- ***Поддерживаемые типы карт*** – строка вида *ИМЯ=КОД;ИМЯ=КОД;...*, заполняется автоматически по справочнику «Типы платежных карт». Имена должны совпадать с наименованиями в этом справочнике. Если значение пустое, оплата картой во Фронте кассира будет недоступна;
- ***Режим отладки*** – если *«Да»*, весь обмен с терминалом записывается в журнал регистрации. По умолчанию *«Нет».*

Кнопка *«Значения по умолчанию»* заполняет все параметры значениями по умолчанию. Незаполненные параметры при записи карточки дополняются значениями по умолчанию автоматически.

### Настройка терминала в рабочем месте

В справочнике ***«Рабочие места (компьютеры)»*** (*Справочники → Розница и оборудование → Рабочие места (компьютеры)*) для кассового рабочего места укажите созданный терминал в реквизите ***«Авторизатор»*** – Фронт кассира берет терминал именно оттуда. Подробнее о рабочих местах см. статью «[Рабочие места](../Рабочие%20места/rabochie-mesta.md)».

## Работа кассира

**1.** При запуске Фронта кассира терминал включается автоматически.

**2.** ***Оплата картой:*** выберите безналичную оплату и тип карты – программа передаст терминалу сумму, покупатель прикладывает карту к пинпаду.

**3.** После одобрения банком печатается слип (на фискальном регистраторе, принтере чеков или на пинпаде – в зависимости от параметра *«Печать квитанций на пинпаде»*), затем пробивается фискальный чек.

**4.** ***Возврат:*** чек возврата вводится на основании чека на оплату. Номер ссылки (RRN) исходной операции запрашивает сам пинпад.

**5.** ***Закрытие смены:*** при закрытии смены на терминале выполняется *сверка итогов,* отчет печатается на фискальном регистраторе или принтере чеков (либо на пинпаде).

Для закрытия смены терминала у пользователя должно быть включено право ***«Разрешить гашение авторизаторов»*** – без него выводится сообщение *«Вам запрещено выполнять эту операцию».* Если у пользователя включено право ***«Разрешить ручную авторизацию безналичных платежей»***, закрытие смены терминала не требуется – выводится сообщение *«Авторизация платежей производится вручную. Закрытие смены не требуется.»*

Права настраиваются в карточке пользователя по кнопке ***«Права и настройки»***, в дереве прав – ветка ***«АРМ → АРМ кассира»***. Права можно задать также для подразделения или организации.

## Ограничения

- Поддерживаются только оплата, возврат и отмена платежа. *Отмена возврата* и *offline-операции* (без связи с банком) не поддерживаются.
- Отменить операцию, результат которой неизвестен, из программы нельзя – только на самом терминале (см. совет «[Результат операции неизвестен – списание могло пройти](../../../../tips/Оборудование/Банковские%20терминалы/%D0%A0%D0%B5%D0%B7%D1%83%D0%BB%D1%8C%D1%82%D0%B0%D1%82%20%D0%BE%D0%BF%D0%B5%D1%80%D0%B0%D1%86%D0%B8%D0%B8%20%D0%BD%D0%B5%D0%B8%D0%B7%D0%B2%D0%B5%D1%81%D1%82%D0%B5%D0%BD%20%E2%80%93%20%D1%81%D0%BF%D0%B8%D1%81%D0%B0%D0%BD%D0%B8%D0%B5%20%D0%BC%D0%BE%D0%B3%D0%BB%D0%BE%20%D0%BF%D1%80%D0%BE%D0%B9%D1%82%D0%B8/rezultat-operacii-neizvesten-spisanie-moglo-proyti.md)»).
- Валюта операций – только рубли.
- Адрес и порт процессинга в программе не настраиваются – только в файле client.ini.
- Если при запуске Фронта кассира связь с процессингом не подтвердилась, прием карт не отключается: связь проверяется заново при каждой операции.

> 🛠 Комментарий для черновика: *Планируется ли добавить во Фронт кассира аварийную отмену последней операции? В драйвере она реализована, но фронт ее не вызывает. Сейчас в статье сказано, что отменить операцию можно только на терминале, аварийная отмена из списка операций убрана. (вопрос задан разработчику (Катя) 01.10.2026, ждем ответа)*

> [!WARNING]
> Если банк одобрил оплату, но программа не смогла принять результат, операция по возможности отменяется на терминале автоматически, и выводится сообщение *«Операция автоматически отменена, повторите оплату»*. Если автоматическая отмена невозможна, программа сообщит, что операцию нужно ***отменить вручную на терминале.***

> 🛠 Комментарий для черновика: *Терминал не входит в схему СЗиУО (система защиты и управления оборудованием через внешнюю компоненту «1С-Рарус»). Обслуживается программным устройством — формой-драйвером «Эквайринг_POSConnector» в обработке «Торговое оборудование»; работает с COM-объектами «POSConnectorInterface-posconlib» (обмен) и «SAPacket-posconlib» (пакет данных).*

> 🛠 Комментарий для черновика: *Мастер: шаг 1/5 «Выберите интеграцию» («Альфа-Авто» / «5S AUTO»), шаг 2/5 «Выберите класс оборудования» (в 5S AUTO: «Облачная касса», «Эквайринг-терминал»), шаг 3/5 «Выберите модель оборудования Эквайринг-терминал». > 🛠 Комментарий для черновика: *Служебные реквизиты справочника «Оборудование»: «Имя обработки драйвера» (строка до 100, для терминала «Эквайринг_POSConnector», скрыт; при пустом значении восстанавливается при записи по классу и модели), «Хранилище параметров драйвера» (хранилище значения). > 🛠 Комментарий для черновика: *Протокол: валюта 643, сумма в копейках; одобрение — код ответа из одних нулей («00» для проверки связи, «000» для финансовых операций). При возврате RRN исходной операции не передается (его запрашивает пинпад, как у Сбербанка); RRN передается при отмене платежа и автоматической отмене. Результаты авторизации попадают в стандартную таблицу безналичных платежей фронта. Журнал регистрации: событие «Оборудование.Эквайринг_POSConnector».*

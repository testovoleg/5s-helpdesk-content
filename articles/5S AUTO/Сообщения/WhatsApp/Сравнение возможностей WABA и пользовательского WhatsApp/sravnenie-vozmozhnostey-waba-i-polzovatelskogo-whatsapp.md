## Введение

Подключить **WhatsApp** к 5S AUTO можно двумя способами: с помощью интеграции с [пользовательским WhatsApp](../Настройка%20интеграции%20с%20WhatsApp/nastroyka-integracii-s-whatsapp.md) и через официальное решение Meta\* – [WhatsApp Business API (WABA)](../Настройка%20интеграции%20с%20WhatsApp%20Business%20API%20%28WABA%29/nastroyki-integracii-s-whatsapp-business-api.md).

Оба решения позволяют вести переписку с клиентами из программы, но процесс подключения, возможности и задачи у них разные.

Подключение *официального WhatsApp Business API* – более трудоемкий и длительный процесс, но данная интеграция позволяет полноценно использовать все функции канала WhatsApp для общения с клиентами.

При работе с WhatsApp при любом способе подключения необходимо принять и не нарушать [Политику обмена сообщениями](https://www.whatsapp.com/legal/business-policy/?content_id=Y5bHWD0s3UAXyGs) и [Правила торговой политики](https://www.whatsapp.com/legal/commerce-policy/?content_id=tgSfxhlLZbd6wmi).

|  | **Интеграция с Whatsapp Business API (WABA)** | **Интеграция с пользовательским WhatsApp** |
| --- | --- | --- |
| ***1. Переписка с клиентами*** |  |  |
| **1.1. Массовые рассылки** | Возможность массовых рассылок и оповещений на любую аудиторию – нужно только согласовать [шаблон](../../Настройка%20шаблонов%20WhatsApp%20Business%20API/nastroyka-shablonov-whatsapp-business-api.md).<br>До 100 000 сообщений в сутки с одного аккаунта. Лимит количества сообщений зависит от истории использования канала и наличия верификации компании *(см. [статью](../Регистрация%20компании%20в%20Facebook%20и%20360dialog/registraciya-kompanii-v-facebook-i-360dialog.md#подтверждение-компании))* | Делать массовые рассылки рискованно. За спам и подозрение в автоматизации аккаунт с очень высокой вероятностью быстро заблокируют |
| **1.2. Интерактивные сообщения** | Возможность добавления кнопок для быстрого отклика клиента:<br><br>Подробнее см. в статье “[Пример индивидуальной настройки WABA](../Пример%20индивидуальной%20настройки%20WABA/primer-individualnoy-nastroyki-waba.md)” | Нет возможности использовать кнопки в сообщениях |
| **1.3. Отправка гиперссылок** | Возможность отправки кликабельных гиперссылок (например, на приложение [5S Link](https://www.5systems.ru/help/nastroyka-prilozheniya-5s-link-v2)): | При отправке гиперссылки в чат клиент не сможет по ней перейти, *пока не добавит контакт в адресную книгу:* |
| **1.4. Тарификация** | Каждый диалог тарифицируется. Стоимость зависит от того, кто первым начал общение: подписчик или компания, и от типа сообщения. Подробнее см. в статье “[Настройка шаблонов WhatsApp Business API](../../Настройка%20шаблонов%20WhatsApp%20Business%20API/nastroyka-shablonov-whatsapp-business-api.md#диалоговая-система-waba)” | Чтобы начать в WhatsApp переписку, нужен только номер телефона клиента.<br>Компания может инициировать переписку с клиентом бесплатно и без ограничения в 24 часа |
| **1.5. Вероятность блокировки аккаунта** | Очень низкая. Ограничение только на вирусную рекламу – но даже в этом случае заблокируют не аккаунт, а шаблон. При повторном нарушении могут уменьшить количество доступных переписок в сутки.<br>Подробнее см. статью “[Возможные проблемы с WABA и их устранение](../Возможные%20проблемы%20с%20WABA%20и%20их%20устранение/vozmozhnye-problemy-s-waba-i-ikh-ustranenie.md)” | При попытке массовых рассылок – высокая.<br>Кроме того, если пользователь захочет с вами связаться через время, а номер будет уже заблокирован, вы потеряете с ним контакт |
| ***2. Взаимодействие с ботом*** |  |  |
| **2.1. Автоматизация** | Автоматизация обслуживания клиентов с помощью ***бота ***– бот может отвечать на стандартные вопросы пользователей моментально и в любое время суток, выдавать информацию по запросам, а также собирать от клиентов обратную связь.<br>Подробнее см. статью “[Возможности бота WhatsApp Business API](../Возможности%20бота%20WhatsApp%20Business%20API/vozmozhnosti-bota-whatsapp-business-api.md)” | Автоматизация возможна, но с учетом ограничений, описанных в других пунктах текущей статьи.<br>Шаблоны и готовые ответы могут использоваться, но только текстовые с картинкой |
| **2.2. Стартовое меню** | Стартовое меню для начала общения с ботом нового пользователя:<br><br>Подробнее см. в [статье](../Возможности%20бота%20WhatsApp%20Business%20API/vozmozhnosti-bota-whatsapp-business-api.md#1-быстрые-ответы-для-нового-чата) | Не предусмотрено |
| ***3. Профиль компании*** |  |  |
| **3.1. Синяя галочка** | Синяя галочка *(ранее зеленая)* и имя компании в профиле WhatsApp после верификации в Facebook\*\*.<br>Больший уровень статуса и доверия клиентов.<br>Пользователю не нужно добавлять номер в контакты: он всегда видит официальное название компании.<br>Подробнее см. в [статье](../Оформление%20аккаунта%20WhatsApp%20Business%20API/oformlenie-akkaunta-whatsapp-business-api.md#подтверждение-компании-в-facebook) | Верификация компании не предусмотрена.<br>Данные аккаунта компании смогут видеть пользователи, сохранившие номер в своей адресной книге.<br>Если номер не сохранен, клиенты будут видеть только номер телефона компании |
| **3.2. Меню быстрых действий** | Использование команд для перехода в ЛК приложения [5S Link](https://www.5systems.ru/help/nastroyka-prilozheniya-5s-link-v2), записи на ремонт, просмотра бонусного счета и т.д.:<br><br>Подробнее см. в [статье](../Возможности%20бота%20WhatsApp%20Business%20API/vozmozhnosti-bota-whatsapp-business-api.md#2-команды) | Не предусмотрено |
| ***4. Подключение*** |  |  |
| **4.1. Надежность работы** | Подключение WABA происходит через официальный ключ API – это самый надежный и стабильный способ работы с WhatsApp | На стабильность работы с WhatsApp влияют обновления мессенджера. Разработчикам нужно некоторое время, чтобы адаптировать работу сервиса под обновления |
| **4.2. Стабильность подключения** | Телефон с приложением WhatsApp не нужен, нет проблемы внезапно слетающей авторизации. Требуется только подключить номер один раз при создании интеграции | Facebook\*\* может разлогинить из привязанных устройств. Это происходит, если в бизнес-аккаунт WhatsApp с телефона не входили более 14 дней, если были перебои сети, если аккаунт заподозрили в спаме или в случае бана. Тогда компания на какое-то время останется без связи, придется повторять процедуру подключения, сканировать QR-код или даже писать в поддержку |
| **4.3. Простота и скорость подключения** | Само подключение WABA занимает несколько минут *(при наличии действующей учетной записи в Facebook\*\* и Facebook\*\* Business Manager).*<br>Также требуется время на создание и согласование [шаблонов](../../Настройка%20шаблонов%20WhatsApp%20Business%20API/nastroyka-shablonov-whatsapp-business-api.md).<br>Чтобы переписываться без ограничений, нужно потратить время на верификацию – подтверждения компании нужно ждать 3-4 дня.<br>Подробнее см. статью “[Регистрация компании в Facebook\*\* и 360dialog](../Регистрация%20компании%20в%20Facebook%20и%20360dialog/registraciya-kompanii-v-facebook-i-360dialog.md)” | Подключение занимает несколько минут.<br>Никаких документов для верификации собирать не нужно – требуется зарегистрироваться, протестировать сервис, настроить интеграцию и можно сразу переписываться с клиентами |

*\*Meta признана экстремистской организацией, запрещенной на территории Российской Федерации.*

*\*\*Facebook является продуктом компании Meta, признанной экстремистской организацией, запрещенной на территории Российской Федерации.*

# Ошибка 22168 Не указан номер терминала (TID)

<table><tr><td><b>Создано:</b> 30.09.2026</td></tr></table>

> *Актуально начиная с версии релиза 5S AUTO **2.8.5**.*

## Проблема

При включении терминала эквайринга, подключенного через POSConnector, или при оплате картой появляется ошибка с кодом 22168:

*«Не указан номер терминала (TID) в параметрах драйвера устройства …»*

## Причина

В параметрах драйвера терминала не заполнен номер терминала (TID), выданный банком.

## Решение

1. Откройте справочник «Оборудование» (см. статью «[Справочник «Оборудование»](https://kb.5systems.ru/articles/5s-auto/torgovoe-oborudovanie/spravochnik-oborudovanie)») и выберите терминал.
2. Выключите терминал: *«Оборудование → Выключить»*.
3. Нажмите *«Оборудование → Настроить параметры»* и заполните параметр ***«Номер терминала (TID)»*** – его выдает банк.
4. Нажмите *«ОК»* и запишите карточку оборудования.
5. Включите терминал: *«Оборудование → Включить»*.

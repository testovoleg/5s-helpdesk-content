# Нулевая сумма в чеке

**Обновлено:** 24.08.2026

<sub>Источник: https://www.5systems.ru/help/reshenie-rasprostranennykh-oshibok-pri-rabote-s-kassoy</sub>

## Проблема

Касса не пропускает документ: в чеке есть строка, где сумма «Всего» равна нулю.

![Ошибка: в таблице «Товары» сумма «Всего» не заполнена](attachments/01-summa-vsego-ne-zapolnena.png)

## Причина

В чеке присутствует строка без 100 % скидки, где сумма «Всего» равна нулю. Сумма «Всего» не может быть равна нулю, кроме случаев, когда это скидка.

## Решение

Есть право **«Не разрешать в чеке строки с 0-й суммой (подарки)»**, которое частично решает проблему.

# Ошибка при возврате

**Источник:** https://www.5systems.ru/help/reshenie-rasprostranennykh-oshibok-pri-rabote-s-kassoy

## Проблема

При оформлении возврата выходит ошибка. Драйвер кассы не поддерживает корректную работу.

![Ошибка выполнения команды «НапечататьТекстПродажиВозврата»: неверный тип шаблона](attachments/01-nevernyy-tip-shablona.png)

## Решение

Рекомендуется откат драйвера ККТ на предыдущую версию.

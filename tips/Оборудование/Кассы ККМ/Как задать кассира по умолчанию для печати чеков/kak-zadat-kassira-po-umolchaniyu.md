# Как задать кассира по умолчанию для печати чеков

<table><tr><td><b>Обновлено:</b> 16.09.2026</td></tr></table>

## Вопрос

В чеках по подразделению нужно печатать одного и того же сотрудника. Сейчас подставляется тот пользователь, который работает в программе, а требуется, чтобы кассир всегда был один.

## Причина

В настройках кассы не заполнен реквизит **«Кассир по умолчанию»**. Пока он пустой, в чек попадает текущий пользователь.

## Ответ

Задайте кассира в карточке кассы — настройка выполняется отдельно для каждой кассы:

1. Откройте *Администрирование → Сервис → Оборудование*.
2. Найдите в списке нужную кассу — по подразделению — и откройте ее карточку.
3. На вкладке **«Типовые настройки»** в блоке **«Дополнительные настройки»** в поле **«Кассир по умолчанию»** выберите нужного сотрудника.
4. Нажмите **«ОК»** или **«Записать»**.

![Реквизит «Кассир по умолчанию» в карточке кассы](attachments/01-kassir-po-umolchaniyu.png)

После этого в чеках по этой кассе печатается выбранный сотрудник независимо от того, кто в этот момент работает в программе.

*Примечание 1:* если в подразделении несколько касс, реквизит нужно заполнить в карточке каждой из них.

*Примечание 2:* если кассир в чеках должен зависеть от того, кто работает в программе, вместо общего реквизита используйте *настройку кассиров ФР* в справочнике «Оборудование»: она позволяет задать кассиров по умолчанию по текущей кассе отдельно для каждого пользователя. Описание см. в статье «[Справочник «Оборудование» → Действия с оборудованием](../../../../articles/5S%20AUTO/Торговое%20оборудование/Справочник%20Оборудование/spravochnik-oborudovanie.md#действия-с-оборудованием)».

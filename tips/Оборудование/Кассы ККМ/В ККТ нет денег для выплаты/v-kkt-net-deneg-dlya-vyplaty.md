# В ККТ нет денег для выплаты

**Источник:** https://www.5systems.ru/help/reshenie-rasprostranennykh-oshibok-pri-rabote-s-kassoy

## Проблема

При возврате денег во время пробития «Чека» работает контроль на остаток денег в кассе. Если средств недостаточно, пробитие чека невозможно — выходит ошибка «В ККТ нет денег для выплаты».

![Ошибка ФР «Нет денег для выплаты»](attachments/01-net-deneg-dlya-vyplaty.png)

## Решение

Проблема решается внесением суммы, равной либо превышающей ту, которую нужно вернуть, — через кнопку на фронте кассира «Внесение».

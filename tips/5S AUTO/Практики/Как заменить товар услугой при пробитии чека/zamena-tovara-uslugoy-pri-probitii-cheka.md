# Как заменить товар услугой при пробитии чека

<table><tr><td><b>Обновлено:</b> 24.06.2022</td></tr></table>

## Вопрос

Как пробивать товар в чеке как услугу?

## Ответ

Открыть *План видов характеристик* ***«Свойства объектов»*** (Сервис → Все операции → План видов характеристик).

![Замена товара услугой - Свойства](attachments/01-zamena-tovara-uslugoy-svoystva.jpg)

Сюда требуется добавить ![Кнопка Добавить](attachments/02-knopka-dobavit.png) новое *свойство* с именем ***«НаименованиеДляЗамены»*** и с указанием *типа значений* ***«Номенклатура»***.

![Замена товара услугой - Наименование для замены](attachments/03-zamena-tovara-uslugoy-naimenovanie-dlya-zameny.jpg)

В *Регистре сведений* ***«Разыменование ссылок»*** нужно добавить ![Кнопка Добавить](attachments/04-knopka-dobavit.png) новую запись:

*Ключ* = ***«ФК_ВариантЗаменыТовара»***

*Ссылка* = ***1*** *(Выбор типа данных = Число)*

![Замена товара услугой - Разыменование ссылок](attachments/05-zamena-tovara-uslugoy-razymenovanie-ssylok.jpg)

В справочнике *«Типы номенклатуры»* либо в самом справочнике *«Номенклатура»* открыть ***Список свойств*** и добавить ![Кнопка Добавить](attachments/06-knopka-dobavit.png) ранее созданное *свойство* ***НаименованиеДляЗамены***. В *значении* необходимо указать *номенклатуру, на которую будет производиться замена*.

![Замена товара услугой - Номенклатура](attachments/07-zamena-tovara-uslugoy-nomenklatura.jpg)

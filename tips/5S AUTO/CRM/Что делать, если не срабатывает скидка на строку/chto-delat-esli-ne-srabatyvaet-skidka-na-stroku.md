# Что делать, если не срабатывает скидка на строку

## Проблема

При выборе в документе скидки она не применяется: сумма по строке остается прежней, колонка «% скидки» не заполняется.

![Скидка выбрана в строке заказ-наряда, но сумма не изменилась](attachments/01-skidka-ne-srabotala.png)

## Причина

Скидка на строку действует только для тех типов номенклатуры, для которых она была задана в документе **«Установка скидки на строку документа»**. Если для типа номенклатуры товара, выбранного в документе, данная скидка не была установлена, она не сработает.

![Тип номенклатуры в карточке товара](attachments/02-tip-nomenklatury-tovara.png)

Типы номенклатуры, для которых задана скидка, можно проверить в документе установки скидок в одноименной колонке:

![Колонка «Тип номенклатуры» в документе установки скидки](attachments/03-dokument-ustanovki-skidki.png)

В приведенном примере у товара тип номенклатуры **«Комплект»**, а скидка «10% на товары» задана для типов **«Штучный»**, **«Моторные масла»** и **«Услуга»**. Для типа номенклатуры "Комплект" эта скидка не была установлена, поэтому она не применилась.

## Решение

Проверьте соответствие типа номенклатуры у товара в документе и типов, для которых задана скидка. При несоответствии добавьте в документ установки скидок строку с нужным типом номенклатуры. Либо выберите в документе другую подходящую скидку для данного товара.

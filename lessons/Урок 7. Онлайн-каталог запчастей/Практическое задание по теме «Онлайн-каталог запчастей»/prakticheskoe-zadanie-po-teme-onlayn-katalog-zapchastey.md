# Практическое задание по теме "Онлайн-каталог запчастей"

<sub>Источник: https://www.5systems.ru/help/prakticheskoe-zadanie-po-teme-onlayn-katalog-zapchastey</sub>

Самостоятельное практическое задание предназначено для закрепления материала, описанного в обучающих видеороликах.

## Описание задания

1. Откройте сохраненную корзину из второго практического задания либо создайте новую выбрав созданный автомобиль.
2. Идентифицируйте автомобиль в онлайн-каталоге.
3. После идентификации станет доступен поиск по оригинальным деталям. Подберите на ваш выбор 5-7 оригинальных деталей. При выборе детали добавляйте в рабочий лист корзины.
4. После добавления запчастей в рабочий лист корзины нажмите на Печать.
5. Выберите вывод рабочего листа.

В результате на печатной форме должны отобразится оригинальные запчасти, добавленные в Корзину.

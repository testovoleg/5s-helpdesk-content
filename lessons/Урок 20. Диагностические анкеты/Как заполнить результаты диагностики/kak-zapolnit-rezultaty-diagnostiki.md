# Как заполнить результаты диагностики

<table><tr><td><b>Время чтения:</b> 3 мин.</td><td><b>Обновлено:</b> 11.04.2025</td></tr></table>

<sub>Источник: https://www.5systems.ru/help/kak-zapolnit-rezultaty-diagnostiki</sub>

Для *занесения результатов проверки* по заполненному бланку диагностической анкеты дважды кликните мышью по анкете в Заказ-наряде. В режиме заполнения анкеты внесите результаты:

1. Двойным кликом мыши отметьте выявленные проблемы и предупреждения по пунктам проверки с указанием причины. Если для причины в анкете установлен список значений, то откроется окно выбора значений с возможностью написать комментарий:<br>
   ![Диагностические анкеты - Заполнение - Комментарий ](attachments/01-diagnosticheskie-ankety-zapolnenie-kommentariy.png)
2. По остальным пунктам проверки заполните, что "все ОК":<br>
   ![Диагностические анкеты - Заполнение - Все ок](attachments/02-diagnosticheskie-ankety-zapolnenie-vse-ok.png)
3. Сохраните изменения:<br>
   ![Диагностические анкеты - Заполнение - Сохранение](attachments/03-diagnosticheskie-ankety-zapolnenie-sohranenie.png)

В результате диагностическая анкета перейдет в состояние "Обработана":

![Диагностические анкеты - Обработана](attachments/04-diagnosticheskie-ankety-obrabotana.png)

Заполненную анкету можно [распечатать](../Как%20распечатать%20результаты%20диагностики/kak-raspechatat-rezultaty-diagnostiki.md) для клиента.

# Практическое задание по теме "АРМ Корзина"

<table><tr><td><b>Время чтения:</b> 1 мин.</td><td><b>Обновлено:</b> 11.09.2026</td></tr></table>

<sub>Источник: https://www.5systems.ru/help/prakticheskoe-zadanie-po-teme-arm-korzina</sub>

Самостоятельное практическое задание предназначено для закрепления знаний по работе в АРМ Корзина, полученных при просмотре курса обучающих видеороликов.

## Описание задания

1. Откройте обращение, созданное после 1-го практического задания. Если его нет, создайте новое.
2. Перейдите в Корзину из обращения.
3. Если у выбранного клиента нет автомобиля, создайте новый. В качестве VIN можно использовать WAUYP34B03NXXXXX – вместо X можно использовать любые цифры, если такой VIN уже присутствует в базе. В процессе создания выберите любую расшифровку.
4. Подберите в вариантах поставки пять товаров.
5. Перенесите два товара из вариантов поставки в корзину
6. Добавьте в корзину две автоработы.
7. Сохраните корзину.
8. Нажмите кнопку печати корзины, выведите на печатную форму товары, работы и варианты поставки.

В результате проделанной работы в печатной форме должны появится товары и работы, добавленные ранее.

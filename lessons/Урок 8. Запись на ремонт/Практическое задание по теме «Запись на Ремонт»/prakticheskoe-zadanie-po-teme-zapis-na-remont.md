# Практическое задание по теме "Запись на Ремонт"

Самостоятельное практическое задание предназначено для закрепления материала, описанного в обучающих видеороликах.

## Описание задания

1. Откройте сохраненную корзину из предыдущих практических заданий.
2. Проверьте, чтобы в корзине было добавлено две и более работ.
3. Перейдите в планировщик из корзины по кнопке Перейти в АРМ "Запись на ремонт".
4. Выберите любой день и запланируйте одну работу на пост.
5. Далее запланируйте вторую работу на другой пост и другое время, но в этот день.

В результате проделанной работы в планировщике должны появится запланированные работы по заявке на разных цехах.

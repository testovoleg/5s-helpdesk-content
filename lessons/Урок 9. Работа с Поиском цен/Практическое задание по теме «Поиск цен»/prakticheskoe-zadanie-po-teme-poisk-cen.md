# Практическое задание по теме "Поиск цен"

Самостоятельное практическое задание предназначено для закрепления материала, описанного в обучающих видеороликах.

## Описание задания

1. Откройте Поиск цен из Корзины клиента, предварительно выбрав клиента.
2. Введите артикул для поиска. Например, 32936 или C2Y32-648ZA
3. Выберите прайс-лист для поиска.
4. В области поиска выберите производителей, если их нашлось более одного, то выберите несколько штук на выбор.
5. В области вариантов поставки отфильтруйте варианты по "Лучшему предложению".
6. Добавьте несколько предложений в корзину.
7. Предложения появились на вкладке "Варианты поставки" в Корзине. Перенесите предложения в Товары Корзины.

В результате полученных действий в Товарах Корзины отобразятся подобранные из Поиска цен запчасти.

# Практическое задание по теме "АРМ Клиенты и Автомобили"

Самостоятельное практическое задание предназначено для закрепления материала, описанного в обучающих видеороликах.

## Описание задания

1. Введите в поиске ФИО клиента.
2. Зарегистрируйте новое обращение.
3. Введите контактные данные клиента.
4. Введите строкой автомобиль клиента.
5. Введите причину обращения *"Практическое задание <ФИО обучающегося>"*.
6. Выберите визит клиента.
7. Откройте обращение.

В результате выполненных действий должно открыться обращение с заполненными ранее полями.
